# 人间牧场

手机横屏 HTML 上帝模拟游戏，使用 HTML、CSS、JavaScript 和 Three.js/WebGL。当前专注浏览器开发与测试，没有平台 SDK、上传或发布打包流程。

## 启动

安装 Node.js 20+，在仓库根目录执行：

```powershell
npm run dev
```

打开 http://127.0.0.1:5173 。服务器直接读取源码，修改后刷新页面即可，无须构建。请通过 HTTP 运行，不要直接双击 HTML。

端口占用时：

```powershell
$env:PORT=5174
npm run dev
```

## 当前规则

双岛同时开局，各有一男一女、4床、120粮；农耕岛一田，畜牧岛一对成年羊。真实配对、幼年成长、生产搬运、自动施工；每岛8名成年人且口粮够18秒才排入低优先级王宫建设，两国均建王宫且各12名成年人后才开放冲突。三神各3技能，共9技能；实际人类死亡逐人收魂，亡灵不重复计魂。

时限300秒、目标300魂。数值严格保留新版策划候选值，**目前实测没有完成300魂，战争阶段通常来不及开放**。功能规则测试通过不等于平衡通过。

## 验证

```powershell
npm test
npm run test:config
npm run balance
npm run config:check
npm run config:sync
```

配置工具使用 Python 3 标准库。Excel 修改经校验后导出 `整理输出/game/rules.json`；校验失败不覆盖有效配置。配置更改后刷新页面再开始新局。

旧版人口百分比繁衍存档不兼容，会明确提示开始新局。存档仅保存在当前浏览器、当前地址的本地存储中。

`整理输出/design/` 和 `整理输出/skills/` 是保留的美术参考，不参与运行。
