# 人间牧场

手机横屏的双岛神力游戏，使用原生 JavaScript 与本地 Three.js，无构建依赖。

## 启动与验证

Node.js 20+：

```sh
npm run dev
npm test
npm run balance
```

浏览器打开 http://127.0.0.1:5173 。服务器直接读取源码，修改后刷新。端口可通过 `PORT` 环境变量修改。没有 npm 时也可直接用 Node 运行 `整理输出/scripts/serve.mjs`。

## 当前玩法

- 双岛各8名成年人、80粮开局。两岛采用相同的经济规则，农田和牧场只是视觉差异。
- 健康成年人自动产粮，所有居民耗粮；有足够健康成年人和口粮才累积出生进度，孩子12秒成年。每岛最多80人，不做性别配对、住房床位、施工或搬运。
- 三神九技能直接可用，统一为“选技能 → 点位置预览 → 点施放”。天气直接选择晴天、降雨、酷热或寒冷。
- 暴怒从范围内现有健康成年人中选2至4人跨桥出征，至少保留2名生产劳动力；每岛最多一队，无国王、外交、军粮、劫掠。出征者与正在迎战的守卫暂时停产。
- 最长出征28秒，损失一半兵员就撤退。和解命中出征者后让双方返乡，并提供12秒停战保护。回乡者重新加入生产。
- 每名人类实际死亡获得1魂、2灵力；不按预估伤亡发奖。尸体保留30秒，可供亡灵技能消耗；亡灵不重复计魂。富余粮食每20秒尝试献12粮换2灵力，留下20秒口粮。
- 300秒内达到60魂成功；全人类灭绝或超时失败。单岛灭绝不会补人，另一岛仍可继续。暂停和切后台停止模拟。

60魂和死亡返2灵力是当前试玩基线。固定种子模拟覆盖观察、战争、养育与分批收魂三种策略；`npm run balance` 会输出结果，养育与分批收魂策略未通关时返回失败。自动策略验证不等于真人难度定稿。

## 代码与配置

- `整理输出/game/engine.js`：人口、经济、技能、战争、死亡和存档。
- `整理输出/game/app.js`：界面、统一施法、触屏与暂停保存。
- `整理输出/game/scene.js`：程序生成的3D双岛、居民、队伍和灾害反馈。
- `整理输出/game/rules.json`：唯一数值配置来源，直接编辑；不再维护或同步Excel配置表。
- `整理输出/game/assets/ui/`：实际使用的三张神明卡牌、九个技能图标和底栏装饰。
- `整理输出/game/vendor/`：Three.js及其许可证，离线运行所需。
- `整理输出/tests/engine.test.mjs`：人口守恒、真实死亡、战争返乡、技能与存档回归测试。

配置修改后刷新并开始新局。改变存档结构或不兼容规则时递增 `config.version`。当前存档版本4，旧版存档提示不兼容；存档仅保留在当前浏览器和地址的本地存储。

仓库仅保留运行资源、开发脚本、测试和本说明，不保存截图、参考图或自动生成的报告。
