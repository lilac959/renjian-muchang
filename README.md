# 人间牧场

一款面向手机横屏的 HTML 上帝模拟游戏。玩家通过神明技能干预世界，居民与国家自主行动。

## 项目状态

目前处于玩法策划阶段，尚未实现可运行的 HTML 游戏。

## 策划资料

- **当前基线：[五分钟核心循环策划案](整理输出/神明也疯狂·手机版策划案（核心循环版）.md)**

单局300秒有效时间、固定1倍速，目标收集300个人类灵魂。围绕“维持人口与生产 → 神力干预 → 实际死亡收魂 → 获得灵力继续干预 → 限期达标”组织玩法、经济配置、操作与反馈。数值已按五分钟节奏填写，仍需在可运行版本中验证平衡。

历史资料（与当前基线冲突时，以当前基线为准）：

- [七大系统策划案](神明也疯狂·七大系统策划案.md)
- [早期手机版策划案整理版](整理输出/神明也疯狂·手机版策划案（系统—功能—反馈整理版）.md)

策划资料中的「神明也疯狂」为原工作名称，项目正式名称为「人间牧场」。

## 技术方向

使用 HTML、CSS 和 JavaScript 实现浏览器游戏，优先适配手机横屏。
