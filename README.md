# 人间牧场

**当前可玩序章：** [序章接入、最新数值、接口与验收](整理输出/序章接入与玩法同步说明.md)。两国各 12 人开局，总人口达到 50 后进入收魂教学；每国人口上限 80，暂不进入现代/未来。序章结束后沿用同一世界，开始 300 秒新增 100 魂挑战。已适配 GitHub 的 v09 双岛场景。

**原版序章复刻参考：** [技术说明、完整对白和接口规范](整理输出/序章复刻参考/序章复刻技术说明.md)。参考目录附三神立绘、演出截图、机器可读流程与源码摘录；保留为原版历史参考；手机版当前实现与数值以“当前可玩序章”文档为准。

**2026-10-31 玩法更新：** 农牧采用不同真实食物链，农耕国按固定地编位置施工后再分方向扩张，欢愉和暴怒按对象生效。规则、表现接入接口与协作边界见 [玩法逻辑交接](整理输出/玩法逻辑交接.md)。施工与动物模型仍由表现负责人按该接口接入；新增序章使用独立对话图层，原有美术渲染保持远端实现。

> 予以生机，亦予归途。

一款面向手机横屏的上帝视角游戏。你掌握生命、天气与死亡三类神力，照看两座岛屿，让居民繁衍、生产，也让他们出征、交战与死亡，在五分钟内收集足够的灵魂。

**维持人口与生产 → 用神力干预 → 实际死亡并收魂 → 获得灵力继续干预 → 在期限内完成目标。**

## 养育与收魂

居民自动生产、耗粮、繁衍和成长。玩家通过神力决定何时扩大人口、何时制造伤亡，以及何时停战恢复。

杀得太早，会失去生产和繁衍的基础；一直养育而不收魂，则会错过期限。

| 当前试玩规则 | 数值与行为 |
| --- | --- |
| 单局目标 | 序章后 300 秒内新增收集 100 魂，达标即成功 |
| 开局 | 序章两岛各 12 名成年人、120 粮，共享 60 灵力；正式挑战继承世界、灵力设为 40 |
| 人口恢复 | 至少2名可繁衍的成年人、足够口粮和生产余量；农耕国还须有床位。欢愉可暂时越过口粮与住房门槛 |
| 成长 | 孩子12秒成年，随后可以生产与出征 |
| 人口上限 | 每岛80人 |
| 死亡收益 | 每名人类实际死亡获得1魂、2灵力 |
| 失败条件 | 未达标时，全人类灭绝或时间耗尽 |

农耕国由真实农田、工人和住房支撑增长；畜牧国通过育羊、保留种羊和真实宰杀获得食物。农耕国固定地编的住宅和农田槽位分别用尽后，才向北扩住宅、向南扩农田；特殊位置先作为民房，达到条件后原地升级。单岛灭绝不补人；动物死亡不收人类灵魂，亡灵死亡也不重复产魂。

## 双岛之间的战争

两座岛屿通过桥梁相连。对**国王**施放暴怒会产生出征意图，国王按真实兵员和停战条件组织战争；对普通居民使用暴怒会令该居民独自出征，不会凭空增加人口。**和解**用于结束冲突。

1. 暴怒的国王留在后方号令，从现有健康、可工作居民中征召1至4人，至少留下2名居民（包括不参与生产的国王）；不够兵员时保留意图并返回原因。
2. 队伍跨桥进攻另一岛，守卫迎战。出征者和正在迎战的守卫暂时停产。
3. 战斗造成真实伤害，只有实际死亡才产生灵魂和灵力。
4. 出征最长28秒，损失一半兵员时撤退；和解可提前让双方返乡，并提供12秒停战保护。
5. 幸存者回到原岛，重新加入生产。每岛最多一支队伍，两次出征至少间隔35秒。

国王来自现有人口，死亡后由存活成年人继任。学院、人口和生产条件满足后可出现脱产学士。反复强征会在高度厌战时引起抗议甚至处死国王；休养和余粮能缓解压力。本轮仍未加入完整外交、军粮、占领与劫掠。

## 三神九技能

序章按教学阶段开放神牌与技能；正式挑战全部可用，每次施放消耗灵力并进入冷却。

| 神明 | 技能 | 灵力 | 冷却 | 主要作用 |
| --- | --- | ---: | ---: | --- |
| 生命 | 和解 | 4 | 10秒 | 选中出征者或下令国王，取消战令并让双方返乡 |
| 生命 | 安居乐业 | 6 | 15秒 | 提高居民产粮效率40%，持续20秒 |
| 生命 | 欢愉时刻 | 6 | 20秒 | 人类享乐停工18秒并催生，随后36秒食量翻倍；羊与野兽加速繁殖 |
| 天气 | 气候控制 | 5 | 12秒 | 改变整座岛屿天气，持续30秒；降雨增产并灭火 |
| 天气 | 闪电 | 3 | 3秒 | 精准击杀范围内最近的一名居民或动物，野兽掉肉 |
| 天气 | 陨石 | 12 | 25秒 | 范围伤害，并在未受降雨保护的落点留下短时火场 |
| 死亡 | 暴怒 | 8 | 22秒 | 精准影响最近目标：国王号令最多4人、平民独自出征、学士袭击同窗、野兽追人 |
| 死亡 | 瘟疫 | 10 | 28秒 | 感染、停产与传播；病程结束有30%概率死亡 |
| 死亡 | 亡灵 | 8 | 24秒 | 消耗最多6具尸体，召唤追击活人的亡灵 |

灵力主要通过人类死亡回流。富余粮食也可自动供奉：每岛每20秒尝试消耗12粮换2灵力，扣粮后仍须保留20秒口粮。

## 操作

- **施法（电脑）：** 选择技能，移动鼠标预览真实范围，点击有效岛屿或桥面直接释放；右键或 Esc 取消。无效不扣灵力，成功后取消选择。
- **施法（手机）：** 选技能后按住地面瞄准、拖动调整、松手释放；移到海面或界面上松手不施放。第二根手指加入即取消本次施法，转为镜头操作。
- **天气：** 选择天气，再瞄准岛屿直接释放，显示整岛边界。
- **查看：** 未选技能时点击居民，高亮人物并显示实时详情；点空地关闭。点岛屿信息牌聚焦镜头。点技能查看说明，可展开详情。
- **镜头（电脑，未选技能）：** 左键拖动平移，右键拖动水平旋转和调整俯视角度，滚轮以鼠标位置为中心缩放。
- **镜头（手机，未选技能）：** 单指拖动平移，双指捏合缩放、扭转旋转、同向上下滑动调整俯视角度。
- **视角：** 水平旋转 360°，俯视角度 25°–80°，支持双岛全景到 7 倍近景；菜单中的“复位视角”回到默认全景，点击岛屿状态卡平滑聚焦。
- **卡牌：** 点击神牌切换神明，悬浮与选中时轻微抬升。触屏直接点击选神。
- **暂停观察：** 点击右上角暂停／继续按钮，或按空格切换。暂停时可操作镜头和查看居民，不能选择技能或施法。
- **菜单：** 左上角按钮或 Esc 打开／关闭菜单。菜单关闭后恢复此前的暂停状态；切后台或切为竖屏后需手动继续。弹层打开时空格不恢复游戏。
- **存档：** 自动保存，也可从菜单“保存并返回首页”；读档后保持暂停。

## 本地运行

需要 **Node.js 20或以上版本**。项目使用原生 JavaScript 与随仓库提供的 Three.js，无须安装依赖或执行构建。

```sh
git clone https://github.com/lilac959/renjian-muchang.git
cd renjian-muchang
npm run dev
```

打开 [http://127.0.0.1:5173](http://127.0.0.1:5173)，使用横屏窗口游玩。修改源码后刷新即可，请通过HTTP访问，不要直接双击HTML文件。

没有 npm 时，可以直接运行：

```sh
node 整理输出/scripts/serve.mjs
```

端口被占用时：

```sh
# macOS / Linux
PORT=5174 npm run dev
```

```powershell
# Windows PowerShell
$env:PORT=5174
npm run dev
```

开发服务器仅监听本机 `127.0.0.1`，同一网络中的手机不能直接访问这个地址。

## 青禾岛场景

当前运行采用远端 v09 双岛资源，见 [v09 美术导入说明](整理输出/game/assets/islands/v09/README.md)；下文保留早期 v03 导入说明作为历史参考。本轮玩法不会修改这些美术资源。

青禾岛使用 Blender v03 原模型：119 个静态物件保留原位置、旋转、尺寸和几何；完整恢复 30,147 个草簇与 528 个麦株实例，保留建筑原贴图。白鹿岛和连接桥保留，经济、技能与战争规则不变。

风动使用源分布、权重、噪声相位与弯曲公式，水岸使用源距离数据；采用 Blender AgX 色彩查找表。网页光照、草叶明暗和水面噪声与 Blender 仍有渲染差异，不能视作逐像素一致。全量 GLB 约 82.4 MiB，首次加载较重，手机性能尚未验收。

导出方法、布局核验与已知差异见 [场景替换说明](整理输出/场景替换说明.md)。启动后可打开 [原视角对照页](http://127.0.0.1:5173/validation/source-scene.html) 检查建筑布局和风浪。

### 国王与技能反馈

皇冠跟随国王头部，号令期间发出红金光；和解、撤退或国王死亡结束号令。旧版同版本存档首次恢复时为每岛现有成年人指定一名国王，不增加人口；已记录国王死亡的存档保持空缺。

流星雨的九条尾迹仅作视觉表现，仍在0.7秒时结算一次范围伤害。死亡剪影、皇冠掉落、灵魂离体、真实感染传播、康复与新生反馈均由实际事件触发；祝福、欢愉、病气和军队气焰跟随居民。动画跟随游戏时间，暂停时冻结。

皇冠使用 [Quaternius 的 Crown](https://poly.pizza/m/i0PZVuVlYv)，840 三角面，CC0 1.0。原始 GLB 与来源说明位于 `assets/characters/royal/`；游戏仅调整佩戴比例、位置和材质光照。

### 音乐与技能音效

游戏内置原创程序生成的76 BPM循环背景音乐，使用柔和钟琴与和弦；无需联网加载音乐或第三方音频素材。首次点击或按键后启用声音。菜单可以分别关闭背景音乐和音效，设置会保留。

九种技能各有音色：和解／祝福／欢愉采用不同清亮音阶，天气分晴雨冷热，闪电带雷击与低频尾音，陨石按下落和真实落地分别播放，普通暴怒使用短促重音、国王号令使用和弦号角，瘟疫使用低沉噪声与不协和音，亡灵使用上升音与幽暗钟声。死亡收魂声限频，避免多人死亡时叠音过响。暂停及切后台停止声音，恢复时不补播积压音效。
