# v16 天空与远海薄雾

来自美术交付 `人间牧场_远海薄雾交付_v16.zip`。可编辑原工程和交付说明原样保存在本地 `整理输出/美术交付/远海薄雾_v16/`（Git 忽略）。程序天空原资源署名：**by威廉_ruby**；来源为用户提供的交付包。

## 接入方式

沿用 v09 模型、碰撞、桥面高度、植被根位置、羊骨骼及动作，无存档版本变更。新增文件为材质与环境增量。

`export-v16-materials.py` 在 Blender 5.2.3 下只读打开源工程，以无光照的 Emission 烘焙地表 Base Color（2048）和牧场 Roughness（1024）。保留源环境属性掩码，原 UV 用于牧场，新农耕 UV 与 v09 导出公式一致。草地底色去除时间变化，运行时恢复风浪颜色。石桥合并并生成 UV 后烘焙暖灰材质，顶点形状与摆放保持不变。不会保存源 blend。

运行时：
- 按新版绿色色带更新草叶；风速、弯曲幅度和羊群动画不变。
- 暖日照、冷天光沿用源方向与颜色；顶部面光以弱方向补光近似。
- 海水采用新版颜色、0.44 泡沫宽度、2.8 浅水距离、0.04 岸波幅度、五秒周期和细波；浏览器噪声近似源程序噪声。海面云影为静态分布，按实机对照减弱反差，避免强斑块。
- 程序天空重建日间渐变和缓慢变化的云，不加载源天空球的全部昼夜、星空、极光分支。
- 远海薄雾在深度后处理中沿视线作八次密度积分，保留源中心清晰椭圆（160×120 源单位）、1—4 倍渐浓范围、高度衰减及 0.004 源密度。源到游戏缩放 0.5，密度换算为 0.008。使用高精度深度采样，UI 不进入雾效。
- AgX LUT 复用，修正曝光差 -0.03 EV，近似源轻微冷暖、饱和度与高光柔晕。雾散射、多重散射和离线光照不是逐像素复现。

## 检查

`/validation/environment.html` 提供相同角度 v09/v16 对照、牧场近景、原 38mm 透视海平线相机及动画播放/暂停。日常游戏仍使用现有正交镜头。诊断参数 `debug=1` 显示场景深度。

完整运行测试：`npm test`。实机需检查总览/近景/海平线、地形拾取、暂停后风浪与羊群同步冻结，以及控制台着色器错误。
