# 人间牧场

一款面向手机横屏的 HTML 上帝模拟游戏。玩家通过神明技能干预世界，居民与国家自主行动。

## 项目状态

已实现 v0.1 可试玩 H5 原型，采用 HTML、CSS、JavaScript 与 Canvas。目标平台为 TapTap H5，优先手机横屏。

这是核心循环验证版，尚未上传 TapTap，也不是完整策划的最终实现。细节差异、验证记录和发布待办见 [发布说明](release/发布说明.md)。

## 本地运行与打包

需要 Node.js，无第三方运行依赖。

```powershell
npm run build
npm run dev
```

浏览器打开 http://127.0.0.1:5173，手机横屏或电脑宽窗口游玩。预览服务仅监听本机，手机不能直接访问电脑的这个回环地址。请通过 HTTP 服务运行，直接双击 HTML 可能被浏览器的 ES Module 安全策略拦截。

```powershell
npm test
node scripts/balance.mjs
```

- `game/`：源文件；技能与全局配置位于 `game/config.js`，其他模拟常数暂在 `game/engine.js`。
- `dist/`：构建后的 H5 游戏目录；TapTap MCP 上传时使用这个相对路径。
- `release/renjianmuchang-h5-v0.1.0.zip`：手动传包用 ZIP，内部单一英文目录，目录内直接包含 `index.html`。
- `tests/`：计时、计魂、收费、存档、完整对局的自动化测试。

## 当前可玩内容

双岛各60人开局、300秒固定1倍速、300魂胜利目标；居民自主生产、生育、衰老、饥饿；羊群与野兽；三位神明与九种技能；技能解锁、冷却、瞄准确认；气候与火山；简化出征；暂停、结算、重新开局与本地存档。

点选神明与技能，再点世界放置落点。闪电和气候立即施放，其他技能需要确认。拖动地图、双指缩放；电脑也可使用滚轮。空格暂停，Esc取消选择或打开菜单。切后台后回到前台仍保持暂停。
