# 双岛 v09 游戏资源

来源：美术交付 `人间牧场_双岛场景_v09_20261031.zip` 中的 Blender 工程，经轻量工程导出。
原始工程保持不变。可编辑压缩版保存在仓库工作目录 `整理输出/美术交付/双岛场景_v09_压缩版/`，约 133 MB（原版约 182 MB）；工程与备份包不纳入 Git。

- 保留双岛、建筑、树木、三孔桥和摆放；不做模型减面。
- 颜色贴图上限 2048，法线及粗糙度等上限 1024。拆分 glTF、几何与图片，单文件小于 GitHub 100 MB 限制。
- 34,575 株植被使用原草叶原型和位置。保留源噪声采样、风速、弯曲幅度及色带；牧场短草采用原 0.25 倍振幅。
- 海面按原岸距场、颜色和五秒周期重建流动及岸线泡沫。浏览器噪声与实时光照并非 Blender 离线渲染的逐像素复现。牧场内小水塘属于地形贴图，保持原画面。
- 12 只羊使用原摆放、骨骼及 `Sheep_Idle` 动作，三个相位错开；文件同时保留 LookAround 和 Walk，当前游戏不让装饰羊离开原草地。
- 风、海水、羊群均使用游戏时间，暂停时同步停止。
- 相同材质静态装饰合批，地形、桥面、植被和骨骼动画保留独立处理。
- 导航高度从原地形和桥面采样，建筑阻挡行走；排除不连通的崖边区域。存档版本 6，旧坐标存档不兼容。

## 再导出

Blender 5.2 后台打开轻量工程，依次执行 `整理输出/scripts/island/export-v09.py` 和 `export-v09-sheep.py`，各自 `--` 后传本目录。然后用 Python 执行 `unpack-gltf.py 本目录/island.glb`。脚本不会保存或修改源工程。`display-lut.bin` 沿用相同 AgX 配置的青禾岛显示 LUT。

对照页面：游戏服务下 `/validation/source-scene.html`。总览、局部与动画开关可检查实际浏览器效果。
