# 场景模型替换

当前为真实 Three.js 几何模型占位，带深度、阴影、射线点选。正式模型在 manifest.json 对应资产 ID 的 url 填入相对 GLB 路径即可加载；空值或加载失败保留占位。

模型采用米制、Y 轴向上、Z 正方向为正面，原点位于落地中心。房屋约宽 2.2 米，居民高 1.8 米。可用 scale / rotationY 适配导出比例与朝向。动画名统一 Idle、Walk、Work；暂缺时播放第一个动画。骨骼每实例独立，逻辑人口、命中半径、存档不依赖网格。

王宫、仓库、祭坛、房屋、农田、羊圈、树木、居民、国王、士兵、羊和亡灵均有固定资产 ID。野兽与火山系统本版不启用。尚无正式 GLB 美术交付，不能将程序占位视为正式资产验收。
