# 双岛、九技能与卡牌 UI 验证

日期：2026-10-31。以用户最新确认的“双岛开局、恢复九技能、其余采用最后补充逻辑”为基线。

## 已实现

- 双岛同时初始化，每岛一男一女、一屋4床、120粮；农耕岛1田，畜牧岛成年公母羊各1只、4栏位。取消人口发现条件，无额外移民，一岛灭绝仍保留场景，全部人类灭绝才失败。
- 原有配对、成长、运输、生产优先、单项施工、献粮、火灾、修复、战争与死亡结算继续运行。王宫需8成年人及18秒实际口粮；双方王宫和各12成年人开启冲突，不能绕过兵员军粮。
- 三神各3技能；瘟疫传播、死亡与免疫恢复，亡灵独立身份、80生命、20秒时限、不重复计魂。
- Three.js本地依赖，真实模型、阴影、射线点选、镜头移动缩放；祭坛、浅滩、火雨、陨石与收魂反馈。固定资产ID及GLB加载/骨骼克隆/动画入口。
- 用户三神原画完整展示，选中长卡抬高；黑金底栏、圆形技能徽章、独立费用与冷却。技能徽章是本地SVG插画，未把参考图职业图标直接充当技能。
- 简洁岛屿条常驻；天气/详情/确认面板避免同时覆盖，教程正文滚动、按钮保留可见；画质设置控制像素密度。
- Excel已同步九技能及新王宫条件，规则存档版本3；旧规则存档拒绝恢复。无平台SDK或打包发布入口。

## 验证记录

- Node模拟回归28项通过：双岛资源只初始化一次、出生/成长、工作/施工、运输/保种、战争条件、死亡奖励、瘟疫、亡灵、存档及暂停；新增单岛灭绝无补人和王宫条件测试。
- Python配置回归5项通过；实际Excel与运行JSON零差异。改动工作表已渲染检查。
- Edge无头浏览器844×390、667×375、932×430、1280×720：双岛状态、每神3技能、解锁取消、天气/详情互斥、菜单暂停、教程和菜单按钮可见、保存继续、竖屏提示；未出现pageerror。最终样式另复核这四个尺寸。

## 平衡仍待验证

固定3种子×3策略，共9局300秒：均超时；出生22—30人，峰值26—31人，收魂0—3。畜牧岛约56.6—60.15秒出现首批搬运肉；9局均未开启冲突。详情见core-balance.json。

测试策略不是最优策略，不能证明目标绝对不可达；但不能据此宣称300魂或五分钟战争体验已通过。保留用户要求的候选数值，未通过自动补人或偷偷降低目标掩盖问题。

## 实际限制

场景仍为程序几何模型，尚无正式GLB美术；已完成接入接口不等于正式资产交付。桌面浏览器模拟不能替代Android/iOS真机触摸、全屏、音频和低端机性能验收。
