## 提示词起点

以下是结构示例，不是固定模板；依照当前需求替换尺寸、颜色和内容。

**空卡牌框**：游戏 UI 单体空框，纵向拱形，复古印刷插画风，哑金细双线与少量叶纹，清楚的外轮廓，轻微纸墨颗粒，人物窗口留空透明，底部保留独立神名区域，不绘制人物，不添加文字，框外透明，完整边缘不裁切。

**技能图标**：表达〔技能行为〕的单体技能徽章，圆形构图，中央以〔主符号〕表达含义，统一环形外框，少量辅助纹样，清楚的大色块与印刷线条，按当前界面的配色，缩小后仍可辨认，不出现英文职业名、费用和水印，外部真实透明。

**横条边框**：横向游戏信息栏，〔指定比例〕，两端紧凑装饰，中央〔需要或不需要〕数字徽章位，文字区大面积留白，细双线与低密度古典纹样，哑光印墨质感，避免高反光金属和大面积发光，按任务要求选择底板或中空透明。
