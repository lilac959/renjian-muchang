# 青禾岛整岛替换

已在原游戏中接入 v03 岛屿，白鹿岛保留原场景与玩法。没有提交、推送或发布。原始 blend 未修改。

## 启动

Node.js 20+，仓库根目录执行 `npm run dev`，打开 http://127.0.0.1:5173/ 。验证使用 `npm test` 和 `npm run balance`。

首次加载会等待岛屿资源，失败显示重试按钮；加载完成前不能开局。布局与移动规则变化后，存档版本升为 5，旧存档提示开始新局。经济、人口、技能和战争数值未修改。

## 素材与复现

输入为 `人间牧场_最新建筑替换_v03.blend`，SHA256：`f4e6c23b7e304199f0ec3728d055f61bdcb2dc815f0f912fb7efa225ec3e719d`。Downloads 与微信原件校验一致。

使用 Blender 5.2.3，在副本上禁用自动脚本执行。先运行 `scripts/island/inspect.py` 检查可见性和预览，再运行 `scripts/island/export.py`。示例从仓库根目录运行：

```sh
/Applications/Blender.app/Contents/MacOS/Blender --factory-startup --disable-autoexec --background /path/to/copy.blend --python 整理输出/scripts/island/inspect.py -- /tmp/island-inspection
/Applications/Blender.app/Contents/MacOS/Blender --factory-startup --disable-autoexec --background /path/to/copy.blend --python 整理输出/scripts/island/export.py -- 整理输出/game/assets/islands/qinghe
```

脚本不保存 blend。源场景共 160 个对象，最终导出 124 个独立语义网格。清单见 [source-inventory.json](validation/island/source-inventory.json)，导出节点的 `sourceName` 保留准确源名称，节点名附加 `__web`。

|---|---|
| `Island_Ground \| 草坡_沙滩_浅滩` | 地形、沙滩与浅滩，独立地面碰撞层 |
| `Cottage Coast/E/NW/S/SE/W \| MH_House_*` | 六处固定住宅，停止青禾岛按人口生成旧房屋 |
| `Granary \| MH_Granary_01` | 粮仓视觉 |
| `Wayside Shrine \| MH_Shrine_01` | 祭坛视觉 |
| `Wheat Plot 00–03`、`Wheat 01–04 \| 12 planted rows` | 四块田与麦穗 |
| `Village Lane`、`Path Edge`、`Path \| Rounded end`、`Village Square` | 原位置道路与广场 |
| `Meadow \| Grass distribution points`、`Coastal Stone*`、`Meadow Stone*` | 草地与石块 |
| `Windmill \| MH_Windmill_02`、`Academy \| MH_School_01`、`Market East/West \| MH_MarketStall_01` | 仅景观，不新增经济倍率 |
| `Village Hall \| MH_Church_01` 及 RoofCore、RoofTilesRepair、TowerWallRepair | 主建筑及必要修补件 |

实际渲染确认以上 MH 建筑实例为可见布局；风车同时属于两个集合，只导出一次。隐藏源资产作为实例/几何节点依赖使用，不重复显示。四个根级原始导入模型位于地面以下，排除；相机、灯光、Wind_Control 与 Sea_Surface 不直接导入游戏。海水使用游戏全局同一个海面。

地面程序材质烘焙为 1024×1024 颜色图。建筑保留基础色、法线与金属/粗糙度贴图，最高 1024 像素。草叶保留每四个分布点中的一个，并保留分布属性；麦穗与风车定向减面。草麦程序配色使用源调色板近似；导出保留 `_WIND_ROOT`、`_WIND_WEIGHT` 自定义顶点属性，运行时通过 GPU 顶点着色器恢复草根固定、草尖弯曲和麦田起伏。风速 1.38、草弯曲幅度 0.5、麦弯曲幅度 0.16、方向 0.88/0.48 来自源 Wind_Control 和几何节点；空间噪声为网页近似。水面按实际岸线生成距离纹理，提供浅深水渐变、细纹与推进消退的白色浪花。所有动画使用对局时间，暂停、后台暂停和结算后同步停止，读档恢复对应相位。所有运行资源和 Three.js r180 加载器本地提供，无 CDN 和外部解码器依赖。

## 地理入口

- `game/assets/islands/qinghe/layout-data.js`：导出生成的地形采样、全岛变换、准确节点名与建筑/石块包围盒。
- `game/island-layout.js`：共享岛屿判定、可施法区域、可行走区域、桥头、障碍和寻路。
- 全岛等比缩放 0.5，glTF 坐标平移 `(28.15285, -0.5, 31.178075)`；Blender Z 向上到 glTF Y 向上的转换只由导出器执行一次。内部布局不变。
- 桥头 `(44,28)` / `(60,28)`，桥宽 2.6，桥面高 0.08。桥模型与引擎共用这份定义。
- 源地形独立向下射线采样，间距 0.25；导航网格间距 0.5，建筑/石块周围留 0.22 的角色余量。A* 后进行可见直线简化，建筑边界使用精确线段检测，避免擦角穿墙。
- 出生、闲逛、追击、迎战、亡灵和跨岛返乡都通过相同导航入口。白鹿岛房屋、仓库、祭坛和羊圈也作为障碍。
- 建筑区域仍可施法；角色拾取独立于导入岛屿。地形高度用于角色、尸体、火焰、陨石、状态标记、飘字及变形技能圈；鼠标地面射线不拾取屋顶。

## 验证结果

[25 项测试全部通过](validation/island/tests.txt)。新增测试覆盖出生/随机目标、建筑和施法区域分离、非屋顶地面、桥两端连通、连续路线、战斗/亡灵合法移动与旧存档拒绝。

[15 组平衡结果](validation/island/balance.jsonl)：组合策略 5/5 通关。原基线组合通关时间 129.6–151.6 秒，新版 123.85–173.6 秒。障碍绕行和合法出生重采样改变了聚集位置、接敌时间和随机序列，故同种子结果不同；未调改经济和技能数值。纯观察/纯战争不保证通关，保持原设计。

实际浏览器验证了冷启动、刷新、失败提示与重试、存档继续、暂停、重新开始、拖动/缩放、安居乐业、欢愉、暴怒、陨石、降雨、闪电、亡灵及瘟疫。出征产生真实伤亡、伤亡过半撤退并返乡；和解的无效目标提示在浏览器验证，双方主动停战返乡由自动回归覆盖。重新开始未重复添加静态岛屿。

## 场景观察操作

`camera-controls.js` 统一管理鼠标、触屏手势和镜头插值。左键/单指平移；右键调整水平角与俯仰；滚轮按鼠标所在的地面参考平面缩放；双指距离、夹角和中心高度分别控制缩放、旋转和俯仰。旋转中心随平移位置移动。镜头高度角限制为 25°–80°，缩放限制为 1–7 倍。

点击岛屿状态卡用 0.5 秒平滑聚焦并打开详情；“复位视角”恢复默认双岛全景。菜单新增“暂停观察”，关闭菜单但保持世界暂停。手势取消、多指转单指、右键拖动都不会变成点击；施法目标保持世界坐标。

自动测试覆盖右键旋转/角度限制、双指操作后的误点击防护、取消手势、缩放锚点、复位与不同角度下的投影反算。浏览器验证暂停观察、岛屿聚焦、平移、滚轮缩放和复位。双指逻辑通过自动事件测试，尚未进行手机触屏真机验证。
