# 青禾岛 Blender 原场景还原

青禾岛使用 `人间牧场_最新建筑替换_v03.blend` 的完整布局；白鹿岛与连接桥保留。原始 blend 未修改。建筑仍是固定景观，市场、学校等不新增玩法。经济、人口、技能、战争和存档版本（v5）未改变。本次地形采样、障碍与桥头数据和上一版一致。

## 还原内容

- 119 个静态物件保留原几何、世界坐标、旋转及缩放，包括地面、道路、建筑、建筑修补件与石块；不再对风车等静态物件减面。
- 全部 30,147 个草簇、四块田各 132 个麦株实例，保留原始分布、尺度与朝向。使用 GPU 实例渲染，不再抽掉四分之三草地。
- 建筑原贴图保留；地形颜色烘焙为 2048×2048。道路与土壤的源程序噪声在 Blender 内采样为顶点颜色。
- 植被的原型、弯曲权重、Blender 噪声相位和风动公式保留。草弯曲 0.5、麦弯曲 0.16、风速 1.38，动画跟随对局时间，暂停时停止。
- 海岸使用源模型 341×341 的 `shore_distance` 数据，还原浅深水渐变、碎泡沫与两道退浪线；白鹿岛保留独立岸线。
- 采用源太阳方向与颜色，并从 Blender OCIO 配置生成 AgX / Medium High Contrast / +0.35 EV 查找表。
- 增加内部对照页 `/validation/source-scene.html`，可切换 Blender 原总览、村庄近景与俯视视角。此页面不读取或覆盖玩家存档。

整岛仅作统一坐标转换：Blender Z 向上转为 Three.js Y 向上，缩放 0.5，平移 `(28.15285, -0.5, 31.178075)`；岛内相对布局不变。桥头保持 `(44,28)` / `(60,28)`，桥宽 2.6。角色继续使用共享地形与寻路入口，建筑仍可施法。

## 核验

- [静态布局核验](validation/island/layout-verification.json)：119 个对象的三角面数量全部一致；变换矩阵最大误差 `4.77e-7`，包围盒最大误差 `9.54e-7`（源坐标单位）。
- [植被运动核验](validation/island/plant-verification.json)：帧 1、48、92，每类分布抽查五个实例的全部原型顶点，对比 Blender 求值几何，最大位置误差 `3.82e-6`。这是抽样数值验证，不是所有帧的逐顶点穷举。
- [30 项回归通过](validation/island/tests.txt)：规则、人口守恒、战争与返乡、地形寻路、镜头手势等。地形采样与障碍未变化，本次未重新运行平衡模拟；旧 `balance.jsonl` 是上一版记录。
- 浏览器确认资源加载、160 人存档继续、暂停观察、岛屿聚焦和双岛桥梁显示，未发现着色器或控制台错误。

## 渲染差异和性能

布局和几何已按原文件保留，但网页截图并非 Blender 渲染的逐像素复刻。Three.js 的天空填充光、阴影和草叶法线照明与 EEVEE 有差异；草色噪声按根部采样，地面程序色经过烘焙/插值；海水保留源岸线和参数，但细碎噪声采用网页 fBm 近似，尚未复刻源水面微凹凸。对照页和源相机用于区分布局问题与渲染差异。

[资源统计](validation/island/asset-stats.json)：GLB 为 86,410,004 字节（约 82.4 MiB），包含 25 张贴图；附加植被、岸线与色彩数据约 2.3 MiB。没有依赖 CDN 或外部解码器。

本次 Apple M4 / 16 GB、macOS 15.7.4、内置浏览器、666×597 CSS 视口、DPR 上限 2，160 人暂停观察近景约 35 FPS；本地获取和解析一次观测约 1.99 秒，不包含完整冷启动编译，也不代表公网下载。保留完整几何和高分辨率阴影增加了负载。未完成手机真机和弱网验收；既有 validation 目录中的旧截图与旧性能记录不作为本版画面依据。

## 导出与复现

源文件 SHA256：`f4e6c23b7e304199f0ec3728d055f61bdcb2dc815f0f912fb7efa225ec3e719d`。使用 Blender 5.2.3，始终在副本上运行，脚本不保存 blend。仓库根目录执行：

```sh
blender --factory-startup --disable-autoexec --background /path/to/copy.blend --python 整理输出/scripts/island/export.py -- 整理输出/game/assets/islands/qinghe
blender --factory-startup --disable-autoexec --background --python 整理输出/scripts/island/verify-layout.py -- 整理输出/game/assets/islands/qinghe
blender --factory-startup --disable-autoexec --background /path/to/copy.blend --python 整理输出/scripts/island/verify-plants.py -- 整理输出/game/assets/islands/qinghe
```

`export-color-lut.py` 使用 PyOpenColorIO 和 Blender 自带的 `datafiles/colormanagement/config.ocio` 生成色彩查找表；运行游戏不需要 Python、Blender 或 PyOpenColorIO。具体命令参数见该脚本开头。

`source-scene.json` 保存原始相机、灯光、风参数、对象核验信息；`plants.bin` 保存分布及噪声采样；`shore.bin` 保存岸线距离；`display-lut.bin` 保存色彩转换。原版隐藏资产仅作实例依赖，不重复显示。源相机与控制器用于还原参数，不作为游戏实体导入。

本地启动 `npm run dev`，测试 `npm test`。镜头保留鼠标平移、右键旋转、滚轮缩放，以及双指缩放/旋转/俯仰；手机触摸手势本次未做真机验证。
