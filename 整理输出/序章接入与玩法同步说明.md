# 手机版序章接入与玩法同步说明

更新日期：2026-10-31。集成基线：远端 `f458c46`（v09 双岛场景）。新开局使用本文规则；`序章复刻参考/` 保留的是原版复刻资料，其中的人口、时代和通关数字不再作为手机版当前验收标准。

## 当前流程与数值

玩家先照顾同一个真实世界，再在这个世界里完成限时收魂。序章不会另建一套假人口，继续挑战也不会重新生成两座岛。

| 项目 | 当前规则 |
| --- | --- |
| 开局 | 两国各 12 名成年人、各 120 粮，共享 60 灵力 |
| 序章养育目标 | 两国总人口达到 50 人；不要求进入现代或未来 |
| 人口上限 | 每国 80 人、两国共 160 人；士兵从这些真实居民中征召，占用人口名额 |
| 教学加速 | 养育阶段世界 3 倍速，正常出生速率再乘 3；教学收魂阶段世界 3 倍速；其余阶段正常速度 |
| 教学收魂 | 闪电实际击杀第一名居民，然后用灾难技能累计取得 10 魂；允许一次攻击超额完成 |
| 谢幕 | 玩家主动施放一次陨石，分成 14 次延迟落点；首次实际命中后拉近镜头、黑屏、显示“神明也疯狂” |
| 正式挑战 | 点击继续后重新计时，300 秒内新增收集 100 魂 |
| 续玩资源 | 保留存活居民、工作身份、粮食、房屋、牧群和研究数据；灵力设为 40，清除序章遗留火场、延迟陨石和冷却 |
| 结束 | 正式挑战达标成功；未达标时人类灭绝或时间耗尽失败 |

普通房屋仍是 5 个床位，人均耗粮仍是 0.4/秒。农耕国以 3 座完成的普通民房、2 块完成的农田开局，其他固定地编槽位等待施工；畜牧国以 18 只真实羊开局。没有通过扩大单屋容量或凭空发粮支撑人口。人口 80 是上限，实际增长仍取决于口粮、生产、成年人数和住房，欢愉保留越过住房与口粮门槛的效果及副作用。

## 阶段与触发条件

| 阶段 | 推进条件 | 神力开放 |
| --- | --- | --- |
| 生命之神开场 | 阅读或略过当前对话 | 生命神牌 |
| 和解教学 | 对正在下令的国王或出征者成功施放和解 | 生命三技能 |
| 天气之神入场、降雨 | 成功对一座岛施放降雨；选错天气或无效落点不推进、不收费 | 生命三技能、气候控制的降雨 |
| 养育 | 真实存活人口达到 50 | 同上，停战保护延续到养育结束 |
| 死亡之神揭示考核 | 对话后，闪电真实击杀一名人类 | 三神入场；第一魂完成前限制其他伤害技能 |
| 教学收魂 | 教学账本达到 10 魂 | 当前手机版三神九技能 |
| 流星雨指令 | 成功支付一次陨石消耗，绑定本次施法的延迟落点实际命中 | 不会因点空、旧陨石或普通死亡误触发 |
| 标题与继续 | 谢幕计时完成且延迟落点处理完毕，玩家点击继续 | 正式挑战全部开放 |

教学账本只记录人类被闪电、陨石、瘟疫、火灾、亡灵实际杀死的数量。动物死亡、自然饥饿、战争死亡不代替教学操作；同一死亡不会重复入账。正式挑战按所有实际人类死亡收魂，**不计入序章已经收集的灵魂**，但世界的历史死亡总数仍保留。

开场和养育阶段阻止人类提前死亡，避免学习操作时任务失效。流星雨谢幕阶段，每岛存活人数降到 8 人后保护剩余人口，便于继续游玩；不会复活此前已死的人。正式挑战解除教学保护。

没有见习上帝台词；没有奇遇或时代演进教学。本轮未增加现代、未来或相关武器科技。现有学士与研究记录保留，但不会触发时代切换。

## 对话与界面接入

- `prologue-data.js` 提供对白、说话者、左右立绘与阶段跳转；玩家没有自动表达感想的台词。
- `prologue-view.js` 使用独立 `#prologue` 图层，双立绘显示，当前说话者高亮，另一位压暗；38 字/秒逐字显示。继续按钮第一次补全文字，第二次推进；支持空格、回车和略过当前对话。
- 对话期间暂停模拟；阶段任务通过真实施法/人口状态完成，不通过点“下一步”伪造结果。`定位目标` 聚焦真实目标，开场国王有标记。
- 可通过任务栏的“直接开始挑战”跳过序章，沿用当时世界状态。
- 谢幕在 2.2 秒内拉近镜头，随后 1.1 秒渐黑、1.4 秒显标题；完整演出约 10 秒。点击继续后恢复双岛视角。
- 三张透明立绘位于 `game/assets/gods/portraits/`，原卡片保持原样。提取方式、尺寸与来源校验见该目录说明及 manifest。
- `prologue.css` 仅控制序章图层和教学期间技能显隐。未替换团队的首页、卡牌、场景模型、人物渲染、战斗动画或收获特效。

## 玩法接口与协作边界

| 文件 | 作用 / 后续修改位置 |
| --- | --- |
| `game/campaign.js` | `CampaignWorld extends World`：真实开局、教学状态机、限制、谢幕、续玩、专用存档校验 |
| `game/prologue-data.js` | 当前序章与挑战数值 `PROLOGUE`，阶段列表和对白；要改 50 人、80 人上限、100 魂或时长从这里修改 |
| `game/prologue-view.js`、`game/prologue.css` | 可单独替换的剧情表现适配层，不在里面修改人口或死亡 |
| `game/engine.js` | 增加可覆写的目标、得分、时钟、人口上限和住房接口；真实死亡携带原因 |
| `game/settlement.js` | 建造与住房使用 world 的人口/住房接口，固定地编优先规则不变 |
| `game/app.js` | 新局入口、暂停输入、神力锁定、存档、序章到挑战的连接 |
| `game/ui.js` | 玩法说明、HUD/结算使用当前 world 目标与得分，不写死旧 60 魂 |
| `tests/prologue.test.mjs` | 阶段、真假触发、计分、续玩与存档回归 |
| `scripts/prologue-audit.mjs` | 三个固定种子的完整教学与限时挑战模拟；不会通过直接增加人口或魂数通关 |

普通基础规则仍在 `game/rules.json`。基础 `World` 保持旧普通对局和当前基础 World 存档的 60 魂语义；网页“开始新局”使用 `CampaignWorld` 的 100 魂目标。改序章数值后刷新并开始新局，勿只改基础 `rules.json` 的目标而忽略 `PROLOGUE`。

先前的固定地编施工、农牧真实食物链、按对象暴怒、欢愉副作用等玩法修改一并保留，细节见 [玩法逻辑交接](玩法逻辑交接.md)。模型仍由表现负责人维护：真实新增建筑的显隐/特殊建筑换模、真实羊群数量与装饰羊同步仍需按接口接入，不能将逻辑施工通过等同于所有模型展示都已完成。
