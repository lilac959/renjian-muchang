- 主岛资源（模型+所引用贴图）由163.92 MB降至23.11 MB，约减少86%；羊5.36→0.29 MB，农民3.98→0.47 MB，牧民3.99→0.47 MB，桥4.62→0.92 MB。这些是指定资源的文件字节数，非整站总下载量，也不是加载耗时承诺。

## 美术更新后的操作
需要Python3和Pillow（支持WebP）。在仓库根目录运行：

    python 整理输出/scripts/build-mobile-assets.py
    python 整理输出/scripts/check-mobile-assets.py
    npm test

生成脚本从原始资源重新构建，不能只更新原图而不更新mobile目录。校验脚本逐字节检查非图片bufferView，并核对节点、网格定义、骨骼、动画和accessor，避免压缩破坏角色动画或场景定位。提交生成资源与代码一起部署。

## 部署注意
- 静态站点必须发布完整game/assets/mobile目录，支持.glb.gz和.webp。加载器兼容服务器直接返回gzip文件和已通过Content-Encoding自动解压两种情况。
- 使用DecompressionStream(gzip)；不支持该接口的旧浏览器回退原模型。推荐在目标手机实际浏览器验证。
- 不要把所有资源预缓存作为进入游戏的前置条件。生产服务器建议为资源提供ETag/Last-Modified，允许缓存后重新验证；当前本地开发服务器仍保持no-store，方便修改即时生效。
- 移动识别条件：粗指针、设备短边≤820、或初始窗口宽度≤600。进入后旋转不会重新下载另一套模型。
