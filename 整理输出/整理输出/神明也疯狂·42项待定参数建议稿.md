# 神明也疯狂 · 42项待定参数建议稿

> 以下为待确认的首轮建议，不覆盖正式策划案。已确定数值保持不变；建议值尚未通过游戏模拟验证。1倍速下50年约25分钟，3倍速下约8分20秒，不含暂停。

核心循环：维持人口与生产 → 用神力干预 → 产生实际死亡并收魂 → 获得灵力继续干预 → 在期限内完成目标。

## 一、开局与资源经济

| 编号 | 项目 | 推荐填写 |
| --- | --- | --- |
| 01 | 初始灵力 | **40点**。足够试用各类技能，也能选择先解锁安居乐业或一个死亡技能。 |
| 02 | 初始人口 | **农耕国60人、畜牧国60人**，合计120人。初始居民均为成年人，年龄均匀分布在20—40岁。 |
| 03 | 初始资源 | **农耕国**：粮食180份、已完工房屋14栋、农田14块、羊0只、野兽8只。**畜牧国**：粮食180份、已完工房屋14栋、农田0块、羊50只、野兽8只，已建羊群栏位总容量60只。两国初始无士兵、无尸体；生产链仍各自维持农耕或畜牧，不新增可交易资源。 |
| 04 | 死亡灵力 | **每个人类实际死亡产生1灵力**；仍只产生1灵魂。闪电击杀人类的灵力收支相抵，但人口和劳力会减少。 |
| 05 | 献粮供奉 | 每国每游戏年检查一次。库存超过**1.5年基础口粮**时，最多供奉1次：消耗**10份粮食，获得5灵力**；扣除后仍须保留1.5年基础口粮。不额外占用一个长期岗位。 |
| 06 | 羊的基础繁殖 | 存活羊群每年新增数量为当前数量的**20%**，用小数累积器平滑产生新羊；出生后即可参与羊群数量计算，不另设幼羊阶段。全岛羊群上限**100只**；超过栏位容量的羊进入公共牧场。 |
| 07 | 宰羊产肉 | **1只羊＝16份粮食**。必须完成宰杀并运回粮仓才入库。 |
| 08 | 野兽产肉 | **1只野兽＝12份粮食**。必须实际死亡、拾取并运回粮仓才入库。 |
| 09 | 欢愉繁殖加成 | 人、羊、野兽的繁殖速率均为**2倍**。人类先停工12秒，随后36秒食欲×2，同时获得36秒繁殖加成；羊和野兽命中后立即获得36秒繁殖加成。羊不承受停工和食欲代价；野兽也不增加额外代价。人类仍须满足住房、余粮条件。 |
| 10 | 降雨增产 | 恒温多云时，农田产量为基础的**125%**。原定羊繁育1.5倍保留。 |
| 11 | 房屋受损容量 | 完好房屋容量仍为5人。以耐久比例分档：**大于50%＝5人；大于0且不超过50%＝2人；0＝废墟、容量0**。损伤本身不凭空结算死亡。 |
| 12 | 效果叠加 | 不同来源的数值修正**相乘**；同一技能不叠加强度。先确定可劳动人数，再计算生产。失能者产出为0，不能靠增益抵消。人类食欲只修改消耗，不直接修改生产。 |
| 13 | 火山恢复期 | 喷发结束后**90模拟秒**。同一段连续高温只触发一次的原规则保留。 |
| 14 | 瘟疫死亡率 | 一次感染在病程结束时有**25%死亡概率**，其余康复；不提前计魂。 |
| 15 | 瘟疫免疫 | 康复后免疫**60模拟秒**。 |
| 16 | 战争与劫掠阈值 | 劫掠：库存不足**0.5年基础口粮**、关系≤−30、可用成年人≥20，且没有进行中的出兵任务。普通宣战：关系≤−60、可用成年人≥30、库存至少0.5年基础口粮。两次出兵至少间隔**60模拟秒**；国王暴怒的额外判定见29。 |
| 17 | 粮仓分档 | 按可支撑年数：**满≥1.5年；半满≥0.75且＜1.5年；见底＞0且＜0.75年；空＝0**。不是给粮仓设置容量上限。 |
| 18 | 预警优先级 | **断粮／发生饿死 → 正在遭受劫掠 → 发生交战 → 粮食见底**。同优先级先显示可支撑时间更短的一国，仍相同则先显示更早发生的事件。 |
| 19 | 自动存档间隔 | 确定沿用**每5个游戏年**；切到后台另行触发自动保存。 |

**口粮口径**：基础口粮按现有人口×2份／年计算，用于供奉和出兵门槛；界面“可支撑年数”、粮仓分档和缺粮预警按当前实际消耗速率计算，包含欢愉的食欲效果。人口为0时不显示除以0的结果。

## 二、人口与生产规则

| 编号 | 项目 | 推荐填写 |
| --- | --- | --- |
| 20 | 正常出生 | 每国每年基础出生数为**当前人口的6%**，采用小数累积器。须有空余已完工住房，且粮食至少能支持**1年基础口粮**。条件不满足时停止累计，不积攒待出生人数。多人出生逐个检查条件。初始每国约3.6人／年。 |
| 21 | 成长与寿命 | **16岁开始劳动，60岁自然死亡**。儿童同样占住房、消耗2份粮食／年。所有成年人均可劳动，不另设退休阶段。自然死亡照常计魂与产出灵力。 |
| 22 | 饥饿 | 居民无法获得所需口粮时，劳动效率降为**50%**；连续缺粮满**15模拟秒**后，每5秒失去20生命，直至死亡。重新吃到粮食后清除饥饿计时、恢复正常劳动，但已损失生命不立刻补满。 |
| 23 | 建房与开田 | 空余住房少于5人或出现露宿时，自动建一栋房，**2人工作15秒**；一次只建一栋。农耕国粮食不足1.5年基础口粮且有可分配劳力时开一块田，**2人工作10秒**，一次只开一块。仅投入劳力和时间，不增设木材等货币；每岛最多30栋房、农耕国最多30块田。清理每只妨碍开垦的野兽按战斗规则，清理每棵树由1人工作3秒。 |
| 24 | 劳力分配 | 优先顺序：**拾取可用兽肉／紧急宰羊 → 维持耕作与牧养 → 修复受损住房 → 新建住房 → 开田**；出兵从空闲成年人中选，不够则从低优先级任务抽调，不能抽空全部食物生产岗位。每块农田2人，只有1人时产量按50%计算。每20只羊配1名牧养工；不足时羊繁殖率按实际／所需工人数同比降低。宰羊或拾取一份兽肉各需1人工作2秒，随后实际搬运入库。安居乐业可提高这些生产工作的效率。 |
| 25 | 羊群管理 | **最低留种30只**。库存低于1.25年基础口粮且羊超过30只时，安排宰羊，达到粮食门槛或留种线即停止；库存低于0.25年基础口粮时可临时突破留种线，但至少保留10只。栏位60只，公共牧场容纳其余羊，全岛总上限100只。 |
| 26 | 野兽行为 | 平时不主动袭击远处居民，被攻击时反击；暴怒期间主动攻击。每年按数量的**10%**繁殖，采用小数累积器，每岛最多20只；种群归零后不自动刷新。 |
| 27 | 房屋修复 | 受损且未烧毁的房屋自动安排**2人工作10秒**修复至完好；房屋着火期间不修复。已烧毁房屋需要按建房规则原地重建，计入原有建筑用地，不额外消耗新资源。 |

## 三、技能与灾害规则

以下生命与耐久仅用于计算伤害，不新增资源：**人类100、羊40、野兽120、亡灵80；房屋与王宫耐久100**。没有饥饿、疾病、火焰或交战伤害时，生物每模拟秒恢复2生命；建筑只通过修复恢复耐久。王宫受损不减少住房容量，损坏时仍可查看国家卡，不增加王宫被毁结局。

| 编号 | 项目 | 推荐填写 |
| --- | --- | --- |
| 28 | 暴怒范围 | **半径5米**；持续时间沿用30秒。 |
| 29 | 暴怒行为 | 暴怒居民、野兽在5米内寻找最近的活人目标，追近至1米后每2秒攻击一次；居民伤害10，野兽伤害15。国王暴怒时每5秒判定一次，**20%概率尝试宣战**，可以绕过关系门槛，但仍需可用成年人≥30、0.5年基础口粮，并遵守出兵间隔；一次暴怒最多促成一次宣战。 |
| 30 | 瘟疫过程 | 命中范围内未感染、未免疫居民**全部感染**。病程20秒；每名感染者每5秒对周围2米内每名易感居民进行一次**20%传播判定**。病程结束按25%概率死亡，否则康复并免疫60秒。重复命中已感染者不重置病程。 |
| 31 | 尸体与亡灵 | 人类尸体保留**60秒**。亡灵移动速度1.5米／秒，攻击距离1米，每2秒造成15伤害；优先攻击最近的活人。普通居民近身反击每2秒造成10伤害，士兵每2秒造成20伤害。闪电可直接消灭亡灵。复苏消耗对应尸体；亡灵死亡或到期消失均不留下可再次复苏的尸体。原定最多12具、存在65秒保留。 |
| 32 | 陨石破坏 | 落下后，对半径5米内生物造成**100伤害**，建筑造成60耐久伤害，树木直接摧毁并在可燃处引火。屋内居民仅在所在房屋被此次冲击摧毁时承受100伤害，按实际居民逐一结算；空屋不产生死亡。 |
| 33 | 火灾 | 每个燃烧点存在**15秒**；每3秒对2米内每个尚未燃烧的可燃对象作一次30%点燃判定。燃烧对象每秒损失5耐久，处于燃烧区的生物每秒损失10生命。同一对象不叠加多份火焰伤害。降雨或降雪在**3秒内灭火**，天气持续期间不能重新点燃。 |
| 34 | 火山喷发 | 持续**10秒**，每秒落下1枚火山弹，共10枚；落点随机位于火山口周围12米内，每枚冲击半径2米，造成50生物伤害、30建筑伤害，并在可燃处引火。喷发或恢复期间再次被陨石命中，不额外触发一轮喷发；陨石自身仍正常结算。 |
| 35 | 重复施法 | 安居乐业、暴怒：刷新剩余持续时间，不叠加强度。欢愉：同一对象仍处于任何欢愉阶段时，不刷新、不叠加，防止反复进入停工阶段；一次范围施法仍可影响其他未受影响对象。瘟疫：已感染或免疫者不再感染。和解：已停火国王为无效目标，**不收费**。范围施法未产生实际效果时仍按通用施放规则反馈；只有亡灵无尸体、闪电无合法目标等既定校验失败情形不收费。 |
| 36 | 心情改善 | **仅保留表情反馈与既定工作效率加成**，不设独立心情值，不让心情额外影响出生、出兵或供奉。 |

## 四、简单战争、预警与结算

| 编号 | 项目 | 推荐填写 |

| 37 | 国家关系 | 用一个双方共用的关系值，范围−100至100，初始0。和平且两国均不缺粮时每年+5；任一国库存低于0.5年基础口粮时每年−10，两项不同时生效。一次劫掠或宣战额外−20。和解只停火，不直接修改关系值。 |
| 38 | 出兵与战斗 | 劫掠派**5人**，宣战派**10人**，均来自实际成年人，出兵期间不生产。出发需携带每人1份粮食并从本国库存扣除，按每人每年2份消耗，不能与国内口粮重复扣除；国家卡仍将他们计入本国人口，单独计算其携带口粮。士兵100生命、移动1.5米／秒、攻击距离1米、每2秒20伤害；普通居民反击每2秒10伤害。无远程兵种。 |

| 40 | 劫掠收益 | 每人最多携带**4份粮食**，5人队伍最多抢20份，且不超过敌方实际库存；抢取时从对方扣除，返回后才入本国库。每次最多点燃1栋房屋，后续损伤遵循火灾规则。抢满、无粮可抢或达到撤退条件即返乡；途中死亡者携粮原地掉落，按拾取流程入库。 |
| 41 | 缺粮预警 | 可支撑年数＜0.75年时橙色预警，＜0.25年或已经有人连续缺粮时红色预警。欢愉预警按“当前库存是否能支付该次人类效果完整48秒的粮食消耗”判断：包含先12秒正常消耗及后36秒受影响者双倍消耗，不预支未来产量。 |
| 42 | 结局优先级 | 同一模拟帧先结算死亡与灵魂，再判定：**达到300魂 → 成功；否则人类灭绝 → 失败；否则期限届满 → 失败**。最后一人死亡或到期同帧恰好达标，均算成功。 |

## 五、这版数值的核对重点

- 初始120人，目标300魂，单靠清空开局人口不能通关，必须维持出生。
- 初始每国年耗粮120份。农耕国14块田年产140份；畜牧国50只羊按20%基础繁殖约新增10只，若宰杀10只可得160份。后者只是足额牧养、顺利搬运且无灾害时的基准，不是保证产量。
- 初始每国住房容量70人，人口60人，留10人增长空间；开局粮食180份相当于1.5年基础口粮。
- 初始60人按6%基础出生率约每国3.6人／年。实际出生会受住房、粮食、气候、欢愉及人口变化影响，不能据此直接保证通关。
- 全员欢愉会明显压低劳动并提高消耗，局部施放更容易维持粮食。高温与暴怒也会损害后续人口供给。
- 房屋、生产和战斗参数需在可运行版本中验证，优先检查：两国能否自行维持、300魂是否可达、是否存在只点闪电就能轻松通关的单一策略。
