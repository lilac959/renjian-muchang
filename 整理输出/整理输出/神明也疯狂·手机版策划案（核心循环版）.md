# 人间牧场 · HTML游戏策划案（手机版·五分钟核心循环版）

> 平台：手机横屏触控。单局300秒有效游戏时间，固定1倍速。本文为当前策划基线；数值集中在资源经济模块维护，尚未通过可运行游戏验证。

---

## 一、玩法模块

### 一.1 游戏定位与核心循环

《人间牧场》是一款上帝模拟游戏。玩家扮演生命、天气、死亡三位神明，用9个技能干预两座岛上的两个国家。

- **核心循环**：维持人口与生产 → 用神力干预 → 产生实际死亡并收魂 → 获得灵力继续干预 → 在期限内完成目标
- **核心矛盾**：人口越多，可收的灵魂越多，但粮食和住房压力也越大；杀死过多人口会损害生产，维持人口太久又可能无法按期完成目标
- **玩家不做的事**：不直接指挥任何居民。居民自主生产、建房、生育和打仗

---

### 一.2 目标、节奏与结算

#### 功能与胜负条件

- 单局上限300秒有效游戏时间，即50游戏年；1游戏年＝6秒。固定1倍速，暂停和切后台停止计时。
- 累计收集300个人类灵魂即成功，可提前结束；未达目标而人类灭绝或期限届满则失败。
- 同一模拟帧先结算死亡与灵魂，再按“达标成功 → 人类灭绝失败 → 超时失败”的顺序判定。最后一个人死亡或期限届满时恰好达标，均为成功。
- 顶部显示剩余分秒；游戏年数放在详情与结算。实际现实用时可因暂停超过5分钟。

#### 对局节奏

| 有效游戏时间 | 体验目标 | 主要决策 |
| --- | --- | --- |
| 0—30秒 | 看懂两国，建立第一次正反馈 | 清兽、降雨、祝福与尝试收魂 |
| 30—90秒 | 生产与人口增长 | 养人口还是解锁杀伤技能 |
| 90—180秒 | 集中收魂后恢复生产 | 杀伤位置、保留劳力、停火 |
| 180—240秒 | 第二轮组合与资源取舍 | 保住人口来源，准备收尾 |
| 240—300秒 | 最后冲刺 | 补足魂数，避免无效施法和灭绝 |

以上是体验目标，不是强制事件脚本；不在固定时刻强制战争或补人口。正常成功局的目标时长为4—5分钟，每10—20秒有一次主要判断。

#### 对应反馈

| 结果 | 显示内容 |
| --- | --- |
| 挑战成功 | “挑战成功”、累计灵魂、有效用时（分秒及对应游戏年数）、两国最终状态 |
| 挑战失败 | “挑战失败”、原因（期限届满／人类灭绝）、已收集灵魂、与目标的差额 |

结算页提供“再来一局”“返回主界面”。

### 一.3 国家冲突与停火

#### 功能与规则

- 两国共用关系值。和平且粮足时缓慢恢复关系，严重缺粮使关系恶化；劫掠与宣战进一步恶化关系。
- 缺粮、关系紧张且有兵员时可劫掠；宣战须满足关系、兵员与口粮条件。国王暴怒可绕过关系门槛，但不能绕过兵员、口粮和出兵间隔。
- 流程：从实际成年人动员 → 扣除携带口粮 → 沿固定浅滩通路实际行军 → 交战或抢粮 → 满足撤退条件后返乡。不得抽空全部食物生产岗位。
- 士兵出兵期间不劳动，仍计入本国人口；使用携带口粮，不能重复扣除国内口粮。返乡后恢复劳动并将剩余携带粮食入库。
- 劫掠粮食先从受害国扣除，实际运回后才进入本国仓库。途中死亡者携带粮食掉落，按拾取流程入库。
- 和解对国王生效时撤回接战命令；对士兵生效时该士兵脱战返乡。停火不直接修改关系值。
- 生物伤害达到实际死亡条件后，才结算灵魂与灵力。触发阈值及队伍参数见“二.7”。

#### 对应反馈

| 事件／状态 | 反馈 |
| --- | --- |
| 劫掠 | 红色预警条“X国小队正在劫掠Y国”，点按定位 |
| 宣战 | 短横幅“X国向Y国宣战”、战鼓音效；点按跳到战场；战场在屏幕外时显示指示 |
| 行军与交战 | 战旗、实际行军队列及命中表现 |
| 停火与返乡 | 战旗变白旗、停火倒计时、军队返回箭头；士兵头顶白鸽并转身返乡 |
| 国家边界 | 总览视角下用淡色描边区分两国领土 |

### 一.6 气候与火山

#### 功能与规则

| 温度＼云量 | 多云                   | 少云              |
| ----- | -------------------- | --------------- |
| 高温    | 无雨；田产和人、羊繁殖降低；积热 | 干热；效果同左         |
| 恒温    | 下雨；促进羊繁育和农田；灭火   | 普通气候            |
| 低温    | 下雪；田产和羊繁育降低；灭火   | 寒冷不下雪；效果同左（不灭火） |

**火山规则**

- 本岛连续高温满25秒，触发本岛火山。
- 重复施放高温不会清空积热。施放恒温或低温会中止积热并归零。
- 同一段连续高温只触发1次火山。火山喷发结束后进入60秒恢复期。
- 气候到期后，岛屿恢复普通气候并清除积热；喷发及恢复期内陨石不触发新一轮喷发，但陨石自身正常结算。

#### 对应反馈：气候、积热与喷发

| 状态 | 画面表现 |
| --- | --- |
| 气候 | 天气粒子（雨、雪、热浪）加岛屿上方的小型气候图标和倒计时环 |
| 火山积热 | 积热进度条，火山口烟雾随积热加浓 |

| 事件      | 反馈                                                                       |
| ------- | ------------------------------------------------------------------------ |
| 火山喷发    | 屏幕震动（受开关控制）并出现红色闪光，实际死亡按计魂流程反馈                                              |

### 一.7 组合玩法

#### 功能与组合规则

- **清兽开荒**：闪电清理野兽、陨石清理树林，再用降雨控制火势，居民随后拾肉和拓荒。
- **雨水与欢愉**：恒温多云加上对羊群施放欢愉，羊群快速繁殖。对人类使用时要注意存粮。
- **战争与亡灵**：利用战场遗留的尸体复苏亡灵。
- **陨石与火山**：陨石击中火山会触发喷发。火山弹和火势造成的伤亡按实际对象结算。

## 二、资源经济与配置模块

### 二.1 资源、时间与结算口径

| 项目 | 性质／来源 | 用途／规则 |
| --- | --- | --- |
| 灵魂 | 人类实际死亡产生的累计成绩，只增不减 | 判断300魂目标；每个人类仅结算一次 |
| 灵力 | 初始资源、人类死亡及献粮供奉 | 施法和解锁 |
| 粮食 | 农田生产、宰羊、拾取兽肉及劫掠所得 | 人口消耗、军队口粮、供奉 |
| 人口／劳力／住房 | 对应实际居民、劳动状态和已完工建筑 | 约束生产与生育，不作为额外货币 |

- 只在实际死亡帧计魂；感染、受伤不提前结算。羊、野兽、亡灵不计魂；复苏尸体及亡灵再次死亡不重复计魂。
- 建筑受损不凭空生成死亡；屋内居民按实际实体与伤害逐一结算，空屋不计死亡。
- 基础年口粮＝本国实际人口×2份。生育、供奉、建设及出兵门槛使用基础口粮口径。
- 界面可支撑年数、粮仓分档与缺粮预警按实际消耗速率计算，包含欢愉食欲。出兵居民使用携带口粮，不重复扣国内库存；国家卡分别展示库存与队伍携粮对应的供给状态。
- 人口为0不作除零计算。运行状态写入存档，不写回策划配置。
- 年产量、年出生率等按1年＝6秒累计；技能、建造、战斗等以配置的模拟秒直接计时，不再额外除以5。固定1倍速，暂停全部停止。

#### 对应反馈

| 事件 | 反馈 |
| --- | --- |
| 人类死亡 | 尸体处光点沿弧线飞向顶部；灵魂+1，灵力“+1”，播放收魂音效。多人同时死亡合并为一次大跳动并振动两下 |
| 献粮供奉 | 祭坛金色光点，灵力“+5”浮字；实际库存扣除粮食 |

### 二.2 双岛生产与居民生存

| 国家 | 生产链 |
| --- | --- |
| 农耕国 | 清理野兽 → 砍树清地 → 开垦农田 → 居民耕作 |
| 畜牧国 | 留种养羊 → 羊群繁殖 → 宰羊 → 搬运入库；超过栏位容量的羊进入公共牧场 |

- 羊和野兽数量不等于粮食，宰杀或拾取后必须实际运回才能入库。
- 生育需要空余已完工住房与足够粮食。不满足条件时停止累计出生，不积攒待出生人数；多人出生逐个检查条件。
- 劳力优先级：紧急拾肉／宰羊 → 日常生产 → 修房 → 建房 → 开田。出兵优先抽调空闲和低优先级任务中的成年人，不抽空全部生产岗位。
- 患病、享乐停工期和暴怒居民不劳动；祝福不能使其恢复劳动。不同来源数值倍率相乘，同技能不叠加强度。
- 受损住房容量下降，超出人口露宿；烧毁后原地重建。建筑和实际居民变化同步到国家卡。
- 心情仅保留表情与已规定的效率反馈，不设独立心情数值或额外生育、供奉加成。

| 状态／事件 | 对应反馈 |

## 三、操作与界面模块

### 三.1 界面布局与信息查看

#### 界面原则

1. **能画在世界里的，不做成面板**。粮仓存量、露宿、房屋损坏、天气、建造进度等状态，都由画面直接表现（见“四.1”及玩法模块各项状态反馈）。数字只在玩家主动查看时出现。
2. **按需出现，用完即收**。瞄准、确认、预警、屏外指示只在相关时刻显示，不需要时完全消失。
3. **常驻元素只保留5个**：菜单、灵魂（含剩余分秒）、灵力、暂停按钮、神明卡组。
4. **点对象看信息**。隐藏的信息都可以通过点按对应对象直接查看：点王宫看国家，点居民看居民，点技能看技能。
5. **同一信息只出现在一个常驻位置**，不重复显示。

#### 功能、位置与交互

- **强制横屏**：竖屏时显示全屏提示“请横置手机”，同时暂停游戏。
- **安全区**：所有界面元素都避开刘海、挖孔和底部手势条（使用 `env(safe-area-inset-*)`）。
- **触控尺寸**：可点击元素不小于44×44pt，相邻按钮间距至少8pt。正文字号不小于12pt，关键数字不小于16pt。


### 三.2 镜头与基础手势

#### 镜头功能

- **缩放范围**：最小缩放即为双岛总览，最大缩放能看清单个居民。缩放到上下限时轻微回弹。
- **回到总览**：双指捏合到最小缩放。
- **切换岛屿**：在总览缩放级别下，未选技能时单指点按某座岛，镜头平滑飞到该岛。
- **岛名**：仅在总览缩放级别时显示在岛屿上方，放大后淡出。

> 不设独立的“总览”“切岛”按钮。

| 长按0.4秒   | 查看对象详情；在技能按钮上长按时，显示技能详情卡       | 同左     |
| 双击世界     | 以该点为中心放大一级                               | 不响应，避免误触             |
| 系统返回键／手势 | 按“取消技能 → 关闭卡片、面板或抽屉 → 打开菜单”的顺序处理，每次只执行最前面一项 | 同左                   |

**判定阈值**：手指移动超过10pt即判定为拖动，不算点按。

#### 对应反馈

| 操作             | 反馈                                                |
| -------------- | ------------------------------------------------- |
| 拖动或缩放镜头        | 移动平滑；缩放到上下限时轻微回弹                                  |
| 捏合到总览          | 镜头停在双岛总览，岛名淡入                                      |
| 总览下点按岛屿        | 镜头平滑飞到该岛，岛名淡出                                    |

### 三.3 选择技能、瞄准与施放

#### 操作流程与模式

**选择神明与技能**

1. 点按神明卡，展开该神明的3个技能。在卡组区左右滑动也可以切换神明。
2. 点按技能按钮将其选中。再次点按同一技能即可取消选中。
3. 点按锁定的技能时，直接弹出解锁确认：“解锁瘟疫：16灵力 [解锁]”。

**两步确认（除闪电、气候控制外）**

1. 点按世界放置落点。范围技能显示预览圈，单体技能吸附并高亮目标。
2. 拖动准星调整位置，或点按其他位置重新放置。
3. 点按“✓施放”，或再次点按准星中心，完成施放。
4. 施放后技能保持选中，落点保留，方便原地连续施放。
5. 取消方式：点按“✕”、再次点按当前技能，或使用返回键。

**快速施放模式**：点按世界即直接施放，不弹出确认区。

**各技能的施放方式**

| 技能   | 施放方式          | 说明                             |
| ---- | ------------- | ------------------------------ |
| 闪电   | 快速：点按即施放（带吸附） | 费用低、冷却短，适合连点                   |
| 气候控制 | 选好选项后，点按岛屿即施放 | 见本节下方气候说明                        |
| 其余技能 | 两步确认          | 放置落点并预览后确认施放 |

**防误触与精确瞄准**

- **准星上移**：拖动时，准星显示在手指上方（距离由配置提供，默认60px），避免手指遮挡。松手后，准星停在显示位置。
- **目标吸附**：单体技能会吸附点按位置半径24pt内最近的合法目标。若有多个目标重叠，弹出小列表供选择，例如“士兵A／士兵B／国王”。
- **自动放大**：如果预览圈在屏幕上的直径小于48pt（例如在总览视角下使用瘟疫），放置落点时镜头会自动平滑放大到落点，使预览圈达到可精确瞄准的大小。

**操作提示**：选中技能后，底部显示“点按岛屿放置落点”（快速模式下显示“点按目标施放”）。每个技能只在前3次选中时显示，次数由配置提供。

**气候控制**

1. 选中技能后，底部弹出小面板：温度三选一，云量二选一（不收费）。
2. 选完后，点按岛屿即施放。
3. 面板会记住上次的选择。下次选中技能时，面板折叠为一行摘要，例如“高温·多云 ✎”，点按“✎”可修改。

**暂停中**：可以选技能、放落点、看预览，但“✓施放”按钮置灰并显示“已暂停”。快速模式下点按世界也不施放。

#### 对应反馈：选择、落点与取消

| 操作             | 反馈                                                |
| -------------- | ------------------------------------------------- |
| 点按或滑动神明卡       | 该卡上浮放大，展开3个技能，播放翻牌音效                              |
| 选中技能           | 按钮高亮并轻振；前3次选中时显示操作提示（见“三.3”）           |
| 放置落点           | 出现预览圈和准星，准星落下时轻振，弹出确认区；需要时镜头自动放大到落点  |
| 取消（✕、再点技能、返回键） | 预览圈收回，确认区隐藏，播放轻柔的收回音效                             |

### 三.4 时间与暂停

- 固定1倍速，300秒有效时间倒计时；1游戏年＝6秒。界面不提供调速入口。
- 时间按钮点按暂停／继续。暂停时生产、生育、移动、战斗、冷却、气候、灾害和存档间隔均停止计时。
- 暂停期间可选择技能、放置落点、预览、查看信息和打开菜单，不能确认施放；即时施放技能也不生效。
- 切后台自动暂停并请求保存，回到前台保持暂停。

| 操作 | 对应反馈 |
| --- | --- |
| 暂停／继续 | 暂停时画面饱和度降低，按钮切换⏸／▶ |
| 暂停中施放 | “游戏已暂停，点▶继续后施放”；技能和落点不变 |
| 返回前台 | 根据保存结果提示，见“四.2” |

### 三.6 共用反馈与施放校验

#### 共用反馈元素与通用原则

| 元素    | 用途        | 规格                                            |
| ----- | --------- | --------------------------------------------- |
| 选中高亮  | 当前神明卡和技能  | 发光描边加轻微放大，其余卡片变暗                              |
| 范围预览圈 | 范围技能瞄准    | 放置落点后显示，可拖动。合法时使用技能主色，非法时为红色虚线。圈中心有准星，准星旁显示费用和预估数量 |
| 目标高亮  | 单体技能瞄准    | 吸附到的合法目标显示描边和名称标签；非法目标显示红色描边和原因               |
| 详情卡   | 技能和对象说明   | 长按0.4秒弹出，显示名称与说明；技能详情卡显示费用与冷却。松手后保持显示，点按外侧关闭 |
| 浮字    | 场景中的数值变化  | 从对象头顶上飘1秒后淡出。正面为绿色，负面为红色，灵魂为紫金色。**浮字是命中结果的主要反馈** |
| Toast | 汇总结果或失败原因 | 屏幕中上方（避开刘海）显示2秒。同类消息合并，例如“灵力不足×3”。点按可跳转到相关位置 |
| 按钮抖动  | 不能施放      | 按钮左右抖动0.3秒并闪红，伴随短促的拒绝音和一次振动                   |
| 触感    | 关键操作      | 选中技能振10ms，落点放下轻振，施放成功振20ms，计魂大跳时振两下，失败振30ms   |
| 屏外指示  | 屏幕外的重要对象  | 见“三.1”                                           |
| 预警条   | 持续风险      | 顶部栏下方的橙色或红色横条，只显示最紧急的一条，点按可定位                     |
| 音效    | 每类操作      | 选择、施放、命中、失败、计魂各有独立音效，可整体静音                    |

**通用原则**

1. 先校验再收费。校验失败时不扣灵力、不进入冷却、不播放施法动画，只显示失败原因。
2. 放置落点和拖动准星都不收费，只有确认施放时才收费。
3. 施法动画不等于命中。命中结果以实际结算为准，并另行展示。
4. 施法成功但没有产生效果时，要明确说明“没有效果”及原因。
5. **结果小结按需显示**：范围技能及产生多项结果的施法，结束后显示一条结果小结Toast，例如“陨石：击杀野兽2，损坏房屋1，人类死亡3（+3魂）”。闪电等单体命中只显示浮字，不弹Toast。
6. 冷却期间仍可放置落点和预览。此时准星中心和“✓施放”按钮显示冷却读秒，冷却结束后自动亮起。连续点按时只提示冷却，不重复弹出Toast。

#### 施放判定 → 提示文案 → 表现

| 情况             | 提示文案             | 表现                                    |
| -------------- | ---------------- | ------------------------------------- |
| 灵力不足           | “灵力不足：需要X，当前Y”   | 按钮抖动，顶部灵力数字闪红                         |
| 冷却中            | “冷却中：剩余X秒”       | 冷却遮罩闪烁，确认按钮显示读秒                       |
| 目标非法           | 说明具体原因，见“一.4”     | 准星处显示红色✕                              |
| 落点在海上或地图外（非气候） | “请在岛屿上施放”        | 预览圈变红，确认按钮置灰                          |
| 预览圈过小          | —（自动放大） | 镜头平滑放大到落点                            |
| 吸附到多个目标        | —                | 弹出目标选择列表                              |
| 成功施放           | —                | 灵力浮字“−X”，冷却遮罩开始倒计时，在落点播放技能动画，随后按“三.6”通用原则第5条显示结果 |
| 已施放但没有实际效果     | “已施放，但没有产生效果：原因” | 灰色Toast                         |

#### 事件定位

重要事件的Toast或横幅可点按跳转；战场在屏幕外时显示指示。选中和解或暴怒时，额外指示屏幕外的两国国王。

### 四.2 自动存档与继续游戏

- **自动存档**：每30模拟秒自动保存，切到后台时也自动保存。
- **继续游戏**：从主界面恢复自动存档。恢复人口、粮食、住房、兵员、灾害、气候、冷却、灵魂、灵力、已解锁技能和剩余时间等对局状态。

- **后台返回**：保持暂停；成功保存时提示“已自动暂停并保存，点▶继续”，尚未保存时提示“已自动暂停，点▶继续”。
- **保存成功**：Toast提示“已保存（时间）”。
- **恢复成功**：自动暂停，提示“已读取存档，点▶继续”。
- **存储方式**：localStorage或IndexedDB；空间不足提示“存储空间不足，保存失败”。

### 四.4 HTML手机端实现约束

**防止浏览器干扰**

- viewport 设置为 `width=device-width, initial-scale=1, viewport-fit=cover, user-scalable=no`。
- 画布设置 `touch-action: none`；页面设置 `overscroll-behavior: none`，防止下拉刷新和回弹。
- 禁用长按菜单和文字选择：`-webkit-touch-callout: none`、`user-select: none`。
- 统一使用 Pointer Events 处理触控，并按 pointerId 追踪多指。
- 在输入框中打字时，不响应游戏手势。

**系统返回与全屏**

- 用 History API 压入状态，拦截安卓返回键，按“三.2”手势总表的顺序处理。到达“打开菜单”这一步时不退出页面。
- 安卓使用 Fullscreen API 实现全屏。iOS 不支持时，提示“添加到主屏幕”以获得全屏体验（需提供 PWA manifest）。
- 横屏锁定先尝试 `screen.orientation.lock`；失败时显示“三.1”的竖屏提示。

**音频与触感**

- 音频在首次触摸时解锁（iOS 要求由用户手势触发播放）。
- 触感反馈使用 `navigator.vibrate`，可在设置中关闭。不支持的设备（如iOS）静默跳过，不报错。

**后台与性能**

- 监听 `visibilitychange`：切到后台时自动暂停并自动存档；回到前台时保持暂停，提示“点▶继续”。
- 渲染分辨率最高按2倍 devicePixelRatio 计算。
- 画质分低、中、高三档。低档减少粒子和屏幕震动，并限制为30fps。

### 四.5 配置管理与更新流程

| 部分        | 职责                       |
| --------- | ------------------------ |
| Excel     | 策划维护数值、名称、说明、素材ID、默认操作设置 |

**Excel工作表**

- 全局参数
- 居民与生产
- 技能基础

- 资产

- 操作设置：吸附半径、准星上移距离、长按时长、拖动判定阈值、预览圈最小直径（自动放大阈值）、振动时长、操作提示显示次数、屏外指示数量上限、预警条优先级、粮仓分档阈值

1. 策划修改Excel。
2. AI检查ID、类型、单位、范围和引用，并列出差异。
3. 检查通过后更新JSON。
4. 验证能正常加载，且游戏表现与配置一致。

- 空白单元格保持原值；要删除某项必须明确标记。

- 不擅自调整平衡数值。
- 运行状态（当前人口、库存、剩余冷却）和玩家修改后的设置只保存在存档或本地设置中，不写回Excel。
- 修改后的配置在重新开局后生效。

### 四.6 实现验证重点

- 300秒固定1倍速，暂停不消耗时间；技能、移动、战斗不能被6秒一年再次加速。
- 农耕初始年产160份、年耗120份；初始粮食480份约支持24秒。验证搬运、失能和增益后的实际供给。
- 120人开局，若最终剩40人，则达300魂至少需220个新生人口；50年平均4.4人／年。验证出生、住房和粮食门槛下是否可达，不把算术上限视为通关保证。
- 闪电2费、死亡返1灵力、冷却3秒，不能靠闪电单一策略完成300魂。
- 验证约4—5分钟成功、每10—20秒主要决策的目标，不能用固定时间补人口或强制事件来伪造节奏。
- 验证路径长度、居民密度、范围技能实际命中数、运输效率及羊群留种，按结果再调平衡。
