# 人间牧场玩法逻辑交接

本轮修改概览、175秒实机通关记录及待接入事项见 [玩法改动与本地测试](玩法改动与本地测试.md)。

本轮完成农牧食物链、农耕国建造扩张、欢愉代价与身份暴怒。默认挑战仍为300秒收60魂。本轮只修改玩法、数值和测试，没有修改模型、场景资源、UI、特效或渲染脚本。

**表现接入尚由表现负责人完成。** 现有 `scene.js` 仍按旧规则展示固定GLB和装饰羊，不会自动读取新建造状态来隐藏建筑、播放施工或更换特殊建筑模型。玩法已经依据真实住房、农田、羊群与角色状态计算；完成下面的接口接入后，画面才能与这些状态一致。

## 农耕国建造

固定槽位直接读取既有 `assets/islands/qinghe/layout-data.js` 中的物件名、世界坐标和占地，不能重新随机摆放。全部固定槽位在开局时已存在于数据中，未启用的状态为 `planned`。

- 开局启用2座民房、2片农田，其他固定槽位依次建造。
- 一座完好民房提供5个床位；未完工房屋不提供床位。
- 普通生育要求有床位、健康成年人、实际口粮和可持续生产余量。
- 每次施工消耗2粮，占用1名真实成年平民，施工期间该人不产粮。无人可工作时进度暂停，不凭空产生工人。
- 固定位置施工5秒。向外扩张先清理土地4秒，再施工5秒；附近有野兽时先由施工者狩猎，或由玩家神罚清理。
- 住宅类10个固定槽位全部建成后，才允许住宅向北侧候选区域扩张。4个固定农田位置全部建成后，才允许农田向南侧候选区域扩张。这两个队列分别判断，不要求先用尽另一类槽位。
- 扩张候选地验证陆地、海拔、完整占地、既有建筑、石块、道路和已预留地块，位置确定后不再移动。
- 新建民房完工后会更新该World的碰撞与寻路。脚下恰有角色时将其移到最近可达地面，避免卡在屋内。
- 农耕国是本轮唯一启用建筑扩张的国家；畜牧国保留固定牧栏，不增加城市扩张算法。

固定住宅类槽位：`Cottage NW/W/E/SE/S/Coast` 六座民房，以及 `Village Hall`、`Academy`、`Granary`、`Windmill` 四个特殊位置。四个特殊位置先作为民房使用，升级时原地转换；`id`、坐标和 `sourceNames` 保持不变。

| 特殊建筑 | 最低人口 | 额外条件与作用 |
| --- | ---: | --- |
| 议事厅 hall | 25 | 产能至少为粮耗1.1倍，储粮20秒，消耗5粮 |
| 粮仓 granary | 30 | 产能至少1.15倍，储粮25秒，消耗6粮；储粮上限提高到1.5倍 |
| 风车 windmill | 40 | 产能至少1.2倍，储粮25秒，消耗8粮；农田产出增加15% |
| 学院 academy | 50 | 产能至少1.2倍，储粮25秒，消耗8粮；允许富余平民成为学士 |

升级占用工人8秒。开始升级前须保证扣去原民房5个床位后仍住得下现有人口，升级时这些床位立即预留，普通生育不会再占用它们，避免升级与扩建互相锁死。尚未满足条件时继续使用民房。议事厅在本轮只完成逻辑建筑身份转换，尚未提供独立外交或治理倍率。

## 农牧不同食物链

农耕国的实际入库量来自完工农田及可工作的平民。每片田最多安排4人，每人基础产粮0.9份每秒，气候、安居乐业和风车影响实际产量。继续增加人口而不增加农田，不会自动获得无限产能。

畜牧国开局有12只真实羊，其中6只成年。羊的数据保存在 `world.animals`，与人口、亡魂分别计算。3个固定牧栏各容纳32只羊，羊8秒成年。劳力不足会降低有效繁殖，缺粮时由可工作居民宰羊，每只羊实际死亡后一次入库12份食物。AI保留种羊，并根据人口需求保留足够繁殖能力，紧急缺粮时可以动用更多羊。

**`world.production(c)` 在畜牧国返回可持续供肉预测，不是每帧自动入库。** `world.netFood(c)` 同样是预测；显示实际收入或结算时请读取实际食物变化、`harvested`、`meatCollected` 或 `animal-killed` 事件，不能把预测再次加到粮仓。

羊自然繁殖基础速率为每只成年羊0.065每秒。雨天倍率1.5，动物欢愉倍率4，可以相乘；高温和寒冷影响有效繁殖。畜牧玩法侧重先保留种羊、扩大羊群，再稳定宰羊供粮。

粮耗仍为每人每秒0.4。饥饿按本帧实际能吃到的比例累积，偶尔入库一点粮食不会清空全国的饥饿计时；恢复足额供粮后逐渐缓解。

野兽存在于未开发区域，会袭击附近人类；死亡一次掉8粮，不产生灵魂和灵力。未开发、无人类活动的出生点45秒检查一次补充。欢愉可促进野兽繁殖，每岛最多6只，暴怒扩大其索敌范围并加快追击。该生态逻辑不改动地编树林、植被或现有模型。

## 欢愉和暴怒

### 欢愉时刻

| 对象 | 实际效果 |
| --- | --- |
| 人类 | 18秒享乐停工，不能生产、施工或参与正常科研；至少2名受到欢愉的健康成年人可以催生，暂时无视住房、口粮和正常生产门槛 |
| 享乐结束的人类 | 恢复工作，接下来36秒食物需求变为2倍 |
| 羊 | 繁殖倍率4，与降雨倍率叠加，不套用人类停工与额外食欲 |
| 野兽 | 加快产生真实野兽记录，但仍受每岛上限约束 |

欢愉产生的孩子也计入真实人口和粮耗，不是假人口；全局每岛80人的安全上限仍然有效。贫粮时对大量居民使用欢愉，可能造成停产、住房不足及后续饥荒。

### 暴怒

暴怒选择半径内最近的一个真实目标，不再把范围内平民直接改成一支军队。

| 目标 | 行为 |
| --- | --- |
| 国王 | 增加30秒出征意图，尝试从可用的真实平民中征兵；仍要保留劳力，遵守停战、整顿和已有部队限制。条件不足时返回明确的阻碍，不凭空生兵 |
| 平民 | 停工并追逐、打伤附近成年人；伤者短暂休养、停工 |
| 学士 | 停研，优先攻击学院附近的同窗；没有合适同窗时才在学院周围寻找其他成年人 |
| 士兵 | 保留原军籍和队伍，攻击间隔缩短40% |
| 野兽 | 扩大索敌、加速追击人类 |
| 羊 | 暴怒时停止贡献正常繁殖并攻击附近人类 |

和解可对正在下令的国王或出征士兵使用，取消双方待发意图、清除国王与士兵的怒气并返乡，避免停战后旧战令再次触发。

每国从现有人口中选出国王，不额外加人口。国王死亡后等待8秒，从现有成年人中选出继任者。学院完工、人口达到50且生产储粮有余量后，最多任命2名学士，脱产研究；本轮只记录研究点数，没有接入新的科技时代或科技终局。

军队伤亡增加厌战。没有军队时，厌战随余粮恢复更快，反战压力也会逐渐消退。高度厌战时国王反复强征会积累反战压力，达到阈值后发生民变并真实处死国王，死亡只结算一次。表现方可使用 `king-overthrown` 事件制作动画，本轮不制作动画。

## 给表现负责人的接入接口

`World` 的原有 `humans`、`get`、`cast`、`step`、`serialize`、`restore` 入口保留。不要在渲染层自行增加人口、粮食、羊或建筑产能。

```js
// 整份返回值都是脱离模拟状态的普通数据，修改它不会修改World。
const state = world.gameplaySnapshot();
// 技能实际命中预览，与释放时使用同一套合法目标规则。
const affectedIds = world.preview(skillId, worldPoint, weather);
// 有单调递增sequence的短事件队列，最多128条。
const changes = world.changes.filter(e => e.sequence > lastSequence);
```

`state.islands[0].buildings` 每条数据包含：

| 字段 | 用法 |
| --- | --- |
| `id` | 建筑永久身份，建造或换模都不更换 |
| `source` | `authored` 为现有地编位置，`extension` 为外扩位置 |
| `sourceNames` | 该固定槽位对应的原始物件名；农田同时列出地块和对应麦株组，议事厅包括其修补子件 |
| `x/y`、`footprint` | 已确认的世界地面坐标和占地，不要重新随机摆放 |
| `kind` | 当前有效种类：`house/field/hall/academy/granary/windmill` |
| `promotionTarget` | 特殊位置未来会升级成什么；空值表示普通位置 |
| `state` | `planned/clearing/building/complete` |
| `progress`、`clearProgress` | 0至1的施工和开垦进度 |
| `upgrading`、`upgradeProgress` | 是否正在将占位民房原地升级，以及升级进度 |

接入顺序：

1. 按固定 `sourceNames` 关联现有地编对象，保持其原变换；`planned` 时隐藏该槽位的建筑内容，不隐藏道路、海岛或树林。
2. `clearing/building` 读取逻辑进度；施工表现可以先使用现有资源。
3. 特殊槽位在 `kind==='house'` 时显示民房占位，只有 `kind` 真正变化后才换为特殊模型。
4. `source==='extension'` 时按给定坐标生成模型，后续只更新状态，不重复生成。
5. 羊和野兽从 `state.animals` 绑定模型；移除旧版4只纯装饰羊，避免与真实羊重复计算或显示。
6. 人类从 `state.people` 读取 `role`、`schoolId`、`joy`、`appetite`、`rage`、`wounded`、`workSite`；人口位置与军事身份仍由World维护。
7. 现有 `app.js` 的暴怒预览仍是旧招兵规则，应改为调用 `world.preview(...)`。本轮为避免与界面负责人冲突没有修改该文件。

关键事件有 `construction-planned`、`construction-started`、`construction-completed`、`building-upgrade-started`、`building-promoted`、`land-cleared`、`animal-born`、`animal-killed`、`resident-enraged`、`king-war-order`、`forced-war-protest`、`king-overthrown`、`king-succeeded`、`scholar-appointed`、`joy-afterglow`。事件不是权威账本，队列过期或读档后应从快照重建画面。

## 配置和存档

所有数值继续放在 `game/rules.json`，增加 `settlement`、`husbandry`、`wildlife`、`society` 四组。位置定义来自原地编清单，扩张区域与间距位于 `settlement.expansion`；改动扩张区域时，必须重新检查地形、道路、容量及保存兼容性。

当前存档版本由5升为6。新增羊群、工作、建筑与身份状态，旧v5存档不能直接续玩，需要开始新局。存档保留实际建造进度、种羊、欢愉后续阶段、愤怒、伤势、战争意图、学士和研究点；读档仍暂停。浏览器存储键暂沿用入口原有命名，以载荷中的 `version` 为有效版本，入口脚本本轮不改。

## 验证与后续边界

```sh
npm test
npm run balance
```

`tests/gameplay.test.mjs` 覆盖固定顺序、位置、扩张方向与碰撞、工人与花费、床位、升级、农牧真实食物来源、欢愉阶段、身份暴怒、民变、保存与人口守恒。自动策略改为明确对在任国王使用暴怒，避免用旧招兵语义解释新技能。

默认数值下分别运行5个种子的观察、战争和养育收割策略；确切结果随同本轮代码保存在 `validation/gameplay/2026-10-31.json`。这些是模拟层检查，未把尚未接入的建筑显隐或新角色模型当成已经完成的表现验收。

本轮不扩展畜牧国建筑，不新增完整科技时代、长期占领、贸易、流星雨、火山或恐龙。后续改动这些系统时，优先复用现有真实人口、羊、床位和工作记录。
