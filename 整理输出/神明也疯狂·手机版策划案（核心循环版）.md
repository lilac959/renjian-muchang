## 一、玩法模块

### 一.1 游戏定位、核心循环与本版范围

玩家扮演生命、天气、死亡三位神明，观察居民自主发展，用神力帮助或破坏，在期限内收集足够的人类灵魂。

**核心循环：维持人口与生产 → 用神力干预 → 产生实际死亡并收魂 → 获得灵力继续干预 → 在期限内完成目标。**

- **养与收的取舍**：人口越多，可收的灵魂越多，也需要更多食物和住房。杀得太早会损害生产和繁衍，一直养而不收则可能超时。
- **玩家负责神力干预**：不手动配对、不分配工人、不放置建筑、不直接指挥士兵。居民自动生活、建设和出兵。
- **自动行为必须有解释**：每次变化都能看见触发原因、当前过程和完成结果；阻塞时显示缺少什么。
- **保留**：三位神明、灵力施法与解锁、献粮供奉、气候组合、闪电、陨石、火灾、建筑损伤与修复、国王、士兵、王宫、关系、劫掠、战争、暴怒与和解。
- **本版移除**：火山及积热喷发、瘟疫与传染免疫、亡灵及尸体复苏、野兽及兽肉、砍树清兽的开荒前置。技能编号1—7保留，8—9停用且不复用，不展示空技能占位。
- **简化**：人和羊改为实际成年异性配对繁衍；只有幼年／成年，不做家谱、具体年龄和自然老死。心情只承担原有表情反馈，不增加独立数值。

### 一.2 目标、阶段与结算

#### 胜负与时间

- 单局上限300秒有效时间，固定1倍速；暂停和切后台停止全部模拟。
- 累计灵魂达到目标即成功，可提前结束；目标暂保留原基线300魂，必须验证新开局是否可达。
- 未达目标时，所有已出现岛屿的人类总数为0或时间耗尽则失败。未出现的第二岛不能提供隐藏人口、延后判负或灭绝救援。
- 同帧先处理实际死亡和奖励，再按“达标成功 → 全人类灭绝失败 → 超时失败”判断，终局后不再解锁岛屿或生成对象。
- 顶部显示剩余分秒。游戏年仅是内部生产消耗单位（1年＝6秒），不能用于推导幼年成长；玩家看到的出生、成长和库存供给时间均以秒显示。

#### 逐步展开

| 阶段 | 触发条件 | 内容与反馈 |
| --- | --- | --- |
| 单岛起家 | 开局 | 农耕岛一男一女成年居民、一栋小屋、一块可耕作农田、仓库和供奉点；先看懂种田、出生、成长和建房 |
| 双岛发展 | 农耕岛现存人口首次达到第二岛门槛 | 迷雾散开，提示“发现了另一座有人居住的岛屿”；畜牧岛初始化一次，展示后回到总览；出现固定浅滩通路 |
| 建立国家 | 第二岛出现后 | 两岛分别将王宫加入自动建设队列，完成后从现有成年人选出国王，不生成额外人口 |
| 国家冲突 | 两座王宫完成，且两岛成年人均达到冲突开放门槛 | 提示“两个国家已具备组织军队的能力”；开始关系检查与冲突系统。开放不等于立即出兵，仍检查二.7全部条件 |

- 第二岛与冲突系统均只解锁一次，之后人口下降不撤销解锁。
- 第二岛出现前没有居民、羊或后台生产；出现时生成初始对象一次。不是从第一岛迁民，也不会在死亡后补人补羊。
- 国王是实际成年居民的身份，和平时可劳动；死亡后由存活成年人继任，没有成年人时显示“暂无国王”。王宫不生产人口。
- 未开放战争时，暴怒仍可影响普通居民；国王宣战分支显示“国家冲突尚未开放”。和解没有合法对象时不收费。技能阶段提示不替代灵力解锁。

#### 引导与节奏

首次真实事件依次解释：出生、成年、建房、收魂、供奉、发现新岛、集结出兵。引导不制造人口或强制战争；说明只出现一次并存档。开局提示：“居民会自动生产、生育和建房。用神力影响他们，收取死者的灵魂，并用灵力继续干预。”

预期从家庭成长逐步进入双岛冲突，再在倒计时末段集中收魂。4—5分钟成功、每10—20秒形成一次主要判断仍是体验目标；具体阶段到达时间通过测试记录，不使用固定秒数脚本伪造节奏。

结算显示成功／失败、原因、已收灵魂／目标、有效用时、已发现岛屿及最终状态，提供“再来一局”“返回主界面”。

### 一.3 国家冲突与停火

- 保留两国共用关系值。和平且双方粮足时恢复，严重缺粮时恶化，劫掠和宣战额外恶化。简要界面显示和平／紧张／交战，详细国家卡显示实际关系与各出兵条件。
- 劫掠检查粮食、关系、可用成年人和在外队伍；宣战检查关系、兵员与口粮。国王暴怒按原概率尝试宣战，只绕过关系门槛，不绕过其他条件。
- 出兵流程：实际成年人动员 → 扣除实际携带口粮 → 集结 → 沿浅滩实际行军 → 交战或抢粮 → 撤退返乡。集结不再额外增加一段未配置的出兵延迟。
- 不抽空食物岗位，并尽可能保留本国最后一对可繁衍成年人；不能同时满足队伍人数、生产和保种约束时不出兵。
- 士兵在外不劳动，仍计入人口；消耗携带口粮，不重复扣国内粮食。返乡恢复劳动，剩余携粮入库。
- 战利品从受害国实际扣除，运回才进入本国库存；死亡士兵携粮掉落，后续按实际拾取运输入库。
- 和解命中国王，双方停火并撤回接战军令；命中士兵，仅该士兵脱战返乡。停火不直接修改关系，期间不发起新进攻。
- 实际伤害造成死亡后才结算灵魂和灵力，不用文字事件直接生成伤亡。

| 状态 | 玩家反馈 |
| --- | --- |
| 暴怒尝试 | “国王已暴怒，正在尝试发动战争”；不得承诺必定出兵 |
| 出兵受阻 | 显示实际原因：兵员不足／军粮不足／已有队伍在外／出兵间隔未到／需保留生产与繁衍人口 |
| 动员与携粮 | 集结旗帜、居民换装、仓库扣粮与队伍携粮标记 |
| 劫掠／宣战 | “X国小队正在劫掠Y国”／“X国向Y国宣战”；可点按定位 |
| 行军与交战 | 真实队列、路线、战旗与命中表现；屏外有指示 |
| 停火与返乡 | 白旗、停火剩余秒数、返乡箭头；士兵恢复日常工作 |

### 一.4 神明技能

三神归属、保留技能的费用／冷却／解锁与操作模式沿用原基线，见二.5。生命3项、天气3项、死亡1项；不新增免费技能替代原机制。

#### 一.4.1 和解

对国王施放，使双方停火并撤回接战军令；对士兵施放，使该士兵脱战返乡。

- 预览：选中后标记已出现的国王；吸附合法国王或士兵并显示名称。
- 结果：国王命中时双方战旗变白，显示15秒停火倒计时；士兵头顶白鸽并返乡。
- 无效：“请选择国王或士兵”；已停火国王提示“双方已在停火中”，不施放、不收费。

#### 一.4.2 安居乐业

改善范围内居民心情，提高可工作者效率；不能使停工者恢复劳动，不额外提高生育或供奉。

- 预览：绿色6米圈，标记居民和预计可工作人数。
- 结果：头顶音符、可工作者“效率＋40%”与20秒光环；劳动加成覆盖生产与实际施工。
- 无效或受限：“范围内没有居民”；全部不能工作时明确“当前只能改善心情，不能恢复劳动”。

#### 一.4.3 欢愉时刻

加快配对成年人的生育进度及成年羊的繁殖进度。保留原代价：受影响人类先停工4秒，之后18秒繁殖加成且食欲翻倍；羊立即获得18秒繁殖加成，无停工和食欲代价。

- 只作用于已有配对的成年个体，幼年不进入欢愉状态；一对中至少一方受影响即可获得该对的繁衍加速，双方均受影响也不重复叠加倍率。人类代价按实际被命中的成年个体计算。
- 人类停工阶段没有加速；之后才应用繁衍倍率。两名伴侣的有效状态只提供一份倍率，不把先后命中变成无限叠加。
- 缺粮、没有空床位或羊圈已满仍暂停繁衍；技能不能绕过限制。
- 预览：粉色5米圈，“可加速人类X对、羊Y对”；同时显示受影响成年人数量与粮食风险。若圈内没有可受影响的配对成年个体，不施放、不收费。
- 结果：爱心与“停工4秒”，随后“食欲×2”；出生倒计时随实际倍率更新。条件不足显示“已受祝福，但住房已满／粮食不足”。

#### 一.4.4 气候控制

保留温度三选一、云量二选一，影响生产、繁衍与火势。选择面板直接显示组合结果，不要求玩家背诵倍率。

- 预览：岛屿高亮，显示“恒温＋多云：降雨，促进农田与羊群繁殖”等摘要。
- 结果：天气粒子、岛屿天气图标与30秒倒计时。
- 无效：“请先选择温度和云量”“请点击已发现的岛屿”。

#### 一.4.5 闪电

快速点按，击杀单个室外合法人物或引燃合法燃料；不能击中屋内居民。

- 预览／吸附：显示合法目标描边；最后一对成年居民中的个体使用常驻风险标记，选中技能时提示“击杀可能中断繁衍”，不改变快速施放操作。
- 结果：雷光与轻震，实际死亡时播放收魂、灵力到账反馈；命中燃料则起火。单体只显示浮字。
- 无效：房屋或屋内目标提示“屋内居民无法被闪电命中”；无合法目标提示“附近没有可命中的目标”，均不收费。

#### 一.4.6 陨石

伤害范围内生物、损坏建筑并引火；树林若作为场景可燃物存在，可被摧毁，但不产生木材或成为建设前置。

- 预览：橙色5米圈，“建筑X、生物Y、成年居民Z”；覆盖最后一对成年居民时提示繁衍风险。
- 结果：陨石、弹坑、伤害和火焰；小结列出受损建筑、实际死亡与收魂数量。
- 空地施放仍正常收费并提示“陨石只造成了地形破坏”。屋内居民是否受伤按二.5判断。

#### 一.4.7 暴怒

保留范围／国王模式：国王倾向宣战，普通居民停工并攻击附近活人。

- 预览：红色5米圈；靠近国王时提供“范围／国王”选择，未出现的国王不作屏外提示。
- 结果：红色怒气与15秒倒计时；国王提示战意上升，真正宣战另发事件。
- 原因提示：国家冲突未开放、兵员不足、口粮不足、停战或出兵间隔未到等，不把概率尝试写成必定成功。

### 一.5 技能解锁

- 初始可用技能和需灵力解锁的技能见二.5；安居乐业仍需12灵力解锁。
- 点按锁定技能显示费用与当前灵力；不足时确认置灰并显示“差X”。
- 成功后图标闪金光、灵力扣减，提示“安居乐业已解锁”。阶段未具备合法目标不等于需要再次付费解锁。

### 一.6 气候与火灾

| 温度＼云量 | 多云 | 少云 |
| --- | --- | --- |
| 高温 | 无雨；降低田产与人、羊繁衍 | 干热；同左 |
| 恒温 | 降雨；促进农田与羊群繁衍；灭火 | 普通气候 |
| 低温 | 下雪；降低田产与羊群繁衍；灭火 | 寒冷不下雪；同左生产影响，不灭火 |

天气显示粒子、组合摘要和剩余时间，到期恢复普通气候。重复施放按原持续时间刷新，不新增火山机制。火灾持续、蔓延与伤害见二.6；降雨／降雪灭火，着火期间不修房。

### 一.7 组合玩法

- **雨水与欢愉**：促进生产与繁衍；对人施欢愉必须考虑停工与食欲增长。
- **神罚与恢复**：陨石造成实际伤亡后收魂，用天气灭火，居民再修复住房和恢复生产。
- **暴怒与和解**：促成冲突收魂，在生产和繁衍人口受损过大前停战。
- **供奉与施法**：富余食物自动供奉补充灵力，避免为了短期供奉耗尽人口口粮。

## 二、资源经济与配置模块

### 二.1 资源、时间与收魂口径

| 项目 | 来源 | 用途 |
| --- | --- | --- |
| 灵魂 | 人类实际死亡，每人仅一次 | 累计成绩，只增不减，判断目标 |
| 灵力 | 初始资源、人类死亡、献粮供奉 | 施法与技能解锁 |
| 粮食 | 农田、宰羊、实际运回的劫掠粮食 | 居民消耗、军粮、供奉 |
| 人口／劳力／住房 | 实际居民、劳动状态、已完工建筑 | 决定生产、繁衍和出兵能力，不是货币 |

- 生物受伤不提前给奖励，羊死亡不计魂。空屋毁坏不生成死亡；实际居民受伤逐一结算。
- 基础年口粮＝本国实际人口×2份。基础供给门槛沿用该口径；界面“够吃X秒”按当前实际国内消耗计算，包含欢愉食欲，排除使用携粮的士兵。
- 当前消耗为0显示“暂无消耗”，不除以0。队伍携粮单独显示，不与仓库库存混为一数。
- 农田年产、居民年耗按1年＝6秒换算；繁衍、成长、建造、移动、技能和战斗直接按模拟秒计时，不再次换算。

#### 收魂表现

1. 人类死亡的同一模拟帧，记录已结算标识并增加1灵魂、1灵力。
2. 原地升起淡蓝白色小人形光影，短暂停留后沿弧线飞向顶部聚魂瓶；动画只是反馈，移镜头、合并粒子或读档不能改变奖励。
3. 聚魂瓶闪光，显示“灵魂＋1”；独立灵力图标显示“灵力＋1”。瓶内魂火按目标进度充满，达到施法费用的技能按钮实时恢复可用状态。
4. 多人死亡合并成几束光和“＋N”，仍逐个结算；屏外死亡从对应屏幕边缘飞入，不强制移动镜头。尸体仅作为短暂视觉效果，不是可操作资源。
5. 首次提示：“人死后会留下灵魂，神明自动收取。死亡同时恢复灵力，可继续施法。”

供奉时仓库显示“粮食－20”，供奉点发出金光，灵力位置显示“＋5”。必须让玩家看见资源来自哪里。

### 二.2 自动生活、配对与建设

#### 配对、出生与成长

- 每种生物从一对成年异性开始，同种同岛未配对的成年人／成年羊自动配对。现有伴侣死亡则解除配对，存活者可重新寻找。
- 幼年不能劳动、参战或繁衍；成年后变大并提示“长大了”，自动补缺少劳力的岗位，再与合适个体配对。
- 出生性别按本岛本物种数量较少的一方优先，数量相同交替选择；这是防卡死规则，不模拟家谱。
- 每对持有独立出生进度。人类需空余完工床位及粮食达到门槛，羊需有效栏位及未达种群上限。缺少条件时暂停进度，不积累超额出生；多人同时出生必须逐个重新检查。
- 出生后重置该对进度，孩子从零开始成长；没有伴侣时不积累出生进度。伴侣死亡清除原配对进度，新配对重新计时。
- 欢愉、气候等改变进度速度，同类增益不叠加强度；显示的是按当前条件估算的剩余秒数。被条件卡住直接显示原因，不显示假倒计时。
- 只保留幼年／成年阶段，不再用原16岁成年或60岁老死规则。

#### 生产与劳动

| 岛屿 | 可观察生产链 |
| --- | --- |
| 农耕岛 | 耕作 → 作物成熟 → 收获 → 搬回仓库 |
| 畜牧岛 | 成年羊配对 → 幼羊出生 → 成长 → 宰杀多余成年羊 → 搬肉入库 |

- 一名成年人即可使一块农田正常生产；无人耕作产量为0。完成生产和运输后才入库。
- 羊不是现成粮食；保留至少一对实际成年公母羊，幼羊不宰杀。没有可宰余量时显示“留种中，等待小羊长大”。没有成年繁衍配对时，不以自动宰杀继续减少种群。
- 生产岗位优先保障。剩余可用劳力依次处理：修复／原址重建住房或羊圈 → 新住房 → 扩大食物生产或羊圈 → 王宫建设／修复。严重缺粮时先将空闲和低优先级劳力转向可立即获得食物的任务。
- 建设不能主动抽空全部食物岗位；人手不足则等待，不凭空生成工人。欢愉停工、暴怒等外部效果仍可能导致岗位暂时无人。
- 欢愉停工期与暴怒居民不劳动；安居乐业不能使其恢复劳动。饥饿保留原效率与伤害规则，原因必须可见。

#### 自动建设

每岛共用一个施工名额，修房、建房、开田、羊圈扩建、建王宫都占用它。使用预留地块，无木材货币，无清兽砍树前置。建筑损毁优先原址重建，不重复占用用地。

| 项目 | 触发原因 | 工作与阻塞反馈 |
| --- | --- | --- |
| 住房 | 空余床位≤1或存在露宿居民 | 地基：“住房不足，准备建房”；施工显示进度 |
| 农田 | 农耕国粮低于扩产门槛，现有田已充分安排劳力且产量不足以覆盖消耗，并有可用新增生产劳力 | “食物产量不足，准备开田”；现有田缺工先补工，不盲目增田 |
| 羊圈扩建 | 畜牧国剩余栏位≤1，且未达栏位上限 | 栅栏施工：“羊圈快满了，正在扩建” |
| 修复／重建 | 房屋、羊圈或王宫受损／烧毁，且火已熄灭 | “正在修复住房”；燃烧时“暂不能修复：仍在燃烧” |
| 王宫 | 第二岛出现且本岛没有王宫 | 低优先级自动安排；完成后从现有成年人选国王 |

- 农田产出比较使用当前可工作者与气候修正后的产速，消耗包含食欲状态；暂时停工优先恢复岗位，不能因短时无人工作不断扩田。
- 排队项目显示“等待工人”及实际原因；施工期间工人停工则暂停，恢复后继续，不使用后台空计时。
- 无建设位置显示“建设用地已满”；羊圈达上限显示“羊圈已达上限”。工期是实际工作秒数，路途时间另外计算。
- 建筑受损容量下降，超出居民露宿；烧毁后原地重建。伤亡与房屋容量分别计算，不能按容量变化凭空杀人。

预警秒数与生育／出兵的基础口粮门槛不同，界面应直接列出具体未满足条件，不能用“仓库不红”推断一定可以出生或出兵。

### 二.9 配置维护与校验

- 数值由Excel维护并校验后同步JSON；本文修改仅更新策划，不能宣称已同步游戏或工作表。
- 原“全局参数”承载阶段门槛、关系和战争；“居民与生产”新增性别、幼年、配对、出生周期、栏位与施工配置；“操作设置”承载提示与预警。
- 停用技能8—9及对应状态、提示、存档迁移字段；移除旧百分比出生、年龄死亡、固定数量留种和已删除系统的运行配置，不能让新旧机制同时执行。
- 检查ID、类型、单位、范围、引用与候选值状态；失败保留上一份有效配置。
- 运行状态不写回策划配置；UI读取实际实体与当前配置，不将示例数字作为第二套固定值。配置修改从新局生效。

## 三、操作与界面模块

### 三.1 界面布局与信息查看

#### 界面原则

1. **画面表现与关键状态并存**。出生、成长、生产、建设、行军和收魂用真实动画表达；同时保留人口、床位、食物供给秒数及当前行动，不让玩家必须点开详情才能发现问题。
2. **按阶段展开**。单岛时只展示已发现岛屿，第二岛出现后扩展总览；三神和保留技能按一.4展示，未满足的目标或战争阶段写清原因，不增加另一套付费解锁。
3. **顶部回答目标与资源**：菜单、聚魂瓶及目标、剩余分秒、灵力、暂停；底部是神明卡组。聚魂瓶与灵力使用不同图标和颜色。
4. **每岛一条简短状态**：“人口12｜床位12/16｜食物够30秒”；第二行展示“正在建房：还需6秒”或最紧急的阻塞原因。例子不是固定配置。
5. **点对象看详情**。仓库始终能打开聚落／国家卡，王宫建好后也能打开；点居民看成长、伴侣、工作或停工原因，点地基看建设原因与进度。
6. **提示跟随真实事件**。首次出生、成年、建房、收魂、供奉、发现新岛、出征分别说明一次；不在固定时间自动补人口或强制战争。

#### 功能、位置与交互

- **强制横屏**：竖屏时显示全屏提示“请横置手机”，同时暂停游戏。
- **安全区**：所有界面元素都避开刘海、挖孔和底部手势条（使用 `env(safe-area-inset-*)`）。
- **触控尺寸**：可点击元素不小于44×44pt，相邻按钮间距至少8pt。正文字号不小于12pt，关键数字不小于16pt。

### 三.3 选择技能、瞄准与施放

#### 操作流程与模式

**选择神明与技能**

1. 点按神明卡，展开该神明当前版本的技能（生命3个、天气3个、死亡1个）。在卡组区左右滑动也可以切换神明。
2. 点按技能按钮将其选中。再次点按同一技能即可取消选中。
3. 点按锁定的技能时，直接弹出解锁确认：“解锁安居乐业：12灵力 [解锁]”。

**两步确认（除闪电、气候控制外）**

1. 点按世界放置落点。范围技能显示预览圈，单体技能吸附并高亮目标。
2. 拖动准星调整位置，或点按其他位置重新放置。
3. 点按“✓施放”，或再次点按准星中心，完成施放。
4. 施放后技能保持选中，落点保留，方便原地连续施放。
5. 取消方式：点按“✕”、再次点按当前技能，或使用返回键。

**快速施放模式**：点按世界即直接施放，不弹出确认区。

**各技能的施放方式**

| 技能   | 施放方式          | 说明                             |
| ---- | ------------- | ------------------------------ |
| 闪电   | 快速：点按即施放（带吸附） | 费用低、冷却短，适合连点                   |
| 气候控制 | 选好选项后，点按岛屿即施放 | 见本节下方气候说明                        |
| 其余技能 | 两步确认          | 放置落点并预览后确认施放 |

**防误触与精确瞄准**

- **准星上移**：拖动时，准星显示在手指上方（距离由配置提供，默认60px），避免手指遮挡。松手后，准星停在显示位置。
- **目标吸附**：单体技能会吸附点按位置半径24pt内最近的合法目标。若有多个目标重叠，弹出小列表供选择，例如“士兵A／士兵B／国王”。
- **自动放大**：如果预览圈在屏幕上的直径小于48pt（例如在总览视角下瞄准较小范围），放置落点时镜头会自动平滑放大到落点，使预览圈达到可精确瞄准的大小。

**操作提示**：选中技能后，底部显示“点按岛屿放置落点”（快速模式下显示“点按目标施放”）。每个技能只在前3次选中时显示，次数由配置提供。

**气候控制**

1. 选中技能后，底部弹出小面板：温度三选一，云量二选一（不收费）。
2. 选完后，点按岛屿即施放。
3. 面板会记住上次的选择。下次选中技能时，面板折叠为一行摘要，例如“高温·多云：田产与繁衍降低 ✎”，点按“✎”可修改；每个组合直接说明生产、繁衍和灭火效果。

**暂停中**：可以选技能、放落点、看预览，但“✓施放”按钮置灰并显示“已暂停”。快速模式下点按世界也不施放。

#### 对应反馈：选择、落点与取消

| 操作             | 反馈                                                |
| -------------- | ------------------------------------------------- |
| 点按或滑动神明卡       | 该卡上浮放大，展开该神明保留的技能，播放翻牌音效                              |
| 选中技能           | 按钮高亮并轻振；前3次选中时显示操作提示（见“三.3”）           |
| 放置落点           | 出现预览圈和准星，准星落下时轻振，弹出确认区；需要时镜头自动放大到落点  |
| 取消（✕、再点技能、返回键） | 预览圈收回，确认区隐藏，播放轻柔的收回音效                             |

### 三.4 时间与暂停

- 固定1倍速，300秒有效时间倒计时；1游戏年＝6秒。界面不提供调速入口。
- 时间按钮点按暂停／继续。暂停时生产、配对出生进度、成长、施工、移动、战斗、冷却、气候、火灾和存档间隔均停止计时。
- 暂停期间可选择技能、放置落点、预览、查看信息和打开菜单，不能确认施放；即时施放技能也不生效。
- 切后台自动暂停并请求保存，回到前台保持暂停。

| 操作 | 对应反馈 |
| --- | --- |
| 暂停／继续 | 暂停时画面饱和度降低，按钮切换⏸／▶ |
| 暂停中施放 | “游戏已暂停，点▶继续后施放”；技能和落点不变 |
| 返回前台 | 根据保存结果提示，见“四.2” |

### 三.6 共用反馈与施放校验

#### 共用反馈元素与通用原则

| 元素    | 用途        | 规格                                            |
| ----- | --------- | --------------------------------------------- |
| 选中高亮  | 当前神明卡和技能  | 发光描边加轻微放大，其余卡片变暗                              |
| 范围预览圈 | 范围技能瞄准    | 放置落点后显示，可拖动。合法时使用技能主色，非法时为红色虚线。圈中心有准星，准星旁显示费用和预估数量 |
| 目标高亮  | 单体技能瞄准    | 吸附到的合法目标显示描边和名称标签；非法目标显示红色描边和原因               |
| 详情卡   | 技能和对象说明   | 长按0.4秒弹出，显示名称与说明；技能详情卡显示费用与冷却。松手后保持显示，点按外侧关闭 |
| 浮字    | 场景中的数值变化  | 从对象头顶上飘1秒后淡出。正面为绿色，负面为红色，灵魂为紫金色。**浮字是命中结果的主要反馈** |
| Toast | 汇总结果或失败原因 | 屏幕中上方（避开刘海）显示2秒。同类消息合并，例如“灵力不足×3”。点按可跳转到相关位置 |
| 按钮抖动  | 不能施放      | 按钮左右抖动0.3秒并闪红，伴随短促的拒绝音和一次振动                   |
| 触感    | 关键操作      | 选中技能振10ms，落点放下轻振，施放成功振20ms，计魂大跳时振两下，失败振30ms   |
| 屏外指示  | 屏幕外的重要对象  | 见“三.1”                                           |
| 预警条   | 持续风险      | 顶部栏下方的橙色或红色横条，只显示最紧急的一条，点按可定位                     |
| 音效    | 每类操作      | 选择、施放、命中、失败、计魂各有独立音效，可整体静音                    |

**通用原则**

1. 先校验再收费。校验失败时不扣灵力、不进入冷却、不播放施法动画，只显示失败原因。
2. 放置落点和拖动准星都不收费，只有确认施放时才收费。
3. 施法动画不等于命中。命中结果以实际结算为准，并另行展示。
4. 施法成功但没有产生效果时，要明确说明“没有效果”及原因。
5. **结果小结按需显示**：范围技能及产生多项结果的施法，结束后显示一条结果小结Toast，例如“陨石：损坏房屋1，人类死亡3（＋3魂、＋3灵力）”。闪电等单体命中只显示浮字，不弹Toast。
6. 冷却期间仍可放置落点和预览。此时准星中心和“✓施放”按钮显示冷却读秒，冷却结束后自动亮起。连续点按时只提示冷却，不重复弹出Toast。

#### 施放判定 → 提示文案 → 表现

| 情况             | 提示文案             | 表现                                    |
| -------------- | ---------------- | ------------------------------------- |
| 灵力不足           | “灵力不足：需要X，当前Y”   | 按钮抖动，顶部灵力数字闪红                         |
| 冷却中            | “冷却中：剩余X秒”       | 冷却遮罩闪烁，确认按钮显示读秒                       |
| 目标非法           | 说明具体原因，见“一.4”     | 准星处显示红色✕                              |
| 落点在海上或地图外（非气候） | “请在岛屿上施放”        | 预览圈变红，确认按钮置灰                          |
| 预览圈过小          | —（自动放大） | 镜头平滑放大到落点                            |
| 吸附到多个目标        | —                | 弹出目标选择列表                              |
| 成功施放           | —                | 灵力浮字“−X”，冷却遮罩开始倒计时，在落点播放技能动画，随后按“三.6”通用原则第5条显示结果 |
| 已施放但没有实际效果     | “已施放，但没有产生效果：原因” | 灰色Toast                         |

#### 事件定位

重要事件的Toast或横幅可点按跳转；战场在屏幕外时显示指示。选中和解或暴怒时，额外指示屏幕外的两国国王。

### 四.1 视觉方向与状态表达

#### 总体风格

- **世界**：柔和的斜俯视岛屿，聚落、农田、牧场、战场要清晰可辨。在手机屏幕上，总览视角也能分辨两国的边界和主要聚落。

- **原则**：特效不能遮挡居民和结算浮字，也不能遮挡确认区；优先保证观察清晰和操作清晰。

#### 世界状态表达要求

人口成长与配对、粮食、床位、施工原因与进度、劳动／停工原因、气候、战争与国界必须在世界中可读。未知岛不暴露对象。收魂用原地灵魂、飞行路径、聚魂瓶与独立灵力反馈表达，不能仅跳数字。

### 四.2 自动存档与继续游戏

- **自动存档**：每30模拟秒自动保存，切到后台时也自动保存。
- **继续游戏**：从主界面恢复自动存档。恢复人口、粮食、住房、兵员、火灾、气候、冷却、灵魂、灵力、已解锁技能和剩余时间等状态；另存第二岛初始化标记、冲突开放标记、性别与成年阶段、成长进度、伴侣ID与出生进度、羊圈容量、建设队列和工作进度、国王身份、关系检查计时、队伍携粮与出兵间隔、欢愉阶段、供奉计时及已展示引导。读档不能重新赠送初始资源、重生第二岛人口或重复收魂。
- **暂不能保存**：神罚尚未落地时暂缓保存；本局结束后不保存进行中的对局。若切后台时神罚尚未落地，保留补存请求，回来继续游戏并落地后补存。
- **后台返回**：保持暂停；成功保存时提示“已自动暂停并保存，点▶继续”，尚未保存时提示“已自动暂停，点▶继续”。
- **保存成功**：Toast提示“已保存（时间）”。
- **恢复成功**：自动暂停，提示“已读取存档，点▶继续”。
- **存储方式**：localStorage或IndexedDB；空间不足提示“存储空间不足，保存失败”。
- **版本兼容**：存档带规则版本。旧百分比繁衍存档不能直接套用新配对规则；未实现明确迁移时提示“旧版存档不兼容，请开始新局”，不静默补人、补伴侣或重置阶段。

### 四.4 HTML手机端实现约束

**防止浏览器干扰**

- viewport 设置为 `width=device-width, initial-scale=1, viewport-fit=cover, user-scalable=no`。
- 画布设置 `touch-action: none`；页面设置 `overscroll-behavior: none`，防止下拉刷新和回弹。
- 禁用长按菜单和文字选择：`-webkit-touch-callout: none`、`user-select: none`。
- 统一使用 Pointer Events 处理触控，并按 pointerId 追踪多指。
- 在输入框中打字时，不响应游戏手势。

**系统返回与全屏**

- 用 History API 压入状态，拦截安卓返回键，按“三.2”手势总表的顺序处理。到达“打开菜单”这一步时不退出页面。
- 安卓使用 Fullscreen API 实现全屏。iOS 不支持时，提示“添加到主屏幕”以获得全屏体验（需提供 PWA manifest）。
- 横屏锁定先尝试 `screen.orientation.lock`；失败时显示“三.1”的竖屏提示。

**音频与触感**

- 音频在首次触摸时解锁（iOS 要求由用户手势触发播放）。
- 触感反馈使用 `navigator.vibrate`，可在设置中关闭。不支持的设备（如iOS）静默跳过，不报错。

**后台与性能**

- 监听 `visibilitychange`：切到后台时自动暂停并自动存档；回到前台时保持暂停，提示“点▶继续”。
- 渲染分辨率最高按2倍 devicePixelRatio 计算。
- 画质分低、中、高三档。低档减少粒子和屏幕震动，并限制为30fps。

### 四.6 实现验证重点

#### 规则一致性

- 核心循环完整：生产与繁衍维持人口；神力消耗灵力；实际人类死亡同时增加魂与灵力；供奉正确扣粮；在300秒内按目标结算。
- 三神共7项保留技能，费用、冷却、范围和安居乐业解锁费用与二.5一致；欢愉的人类停工、食欲代价仍在，双伴侣命中不叠加倍率。
- 暂停、后台与读档不推进模拟、不重复死亡奖励、不重复创建第二岛、不重复赠送资源。动画中断不丢失已经结算的灵魂或灵力。
- 旧百分比出生与具体年龄死亡不再运行；移除系统没有残余按钮、提示、自动事件或引用。

#### 单岛起家与建设

- 两名居民开局能够安排一人生产、另一人施工；缺工时正确等待，不能因两人施工前置卡死，也不能凭空补工人。
- 第一次出生、成年、住房不足、建房及完工都能从画面理解；没有伴侣、缺粮、无床位、无地块时原因明确。
- 空田先补工，产量不足且有劳力时才扩田；停工与气候变化不会引发无意义连续开田。
- 房屋损坏、容量下降、露宿、灭火、修房／重建按实际状态衔接，不以容量变化替代真实死亡。

#### 第二岛与战争

- 第一岛现存人口达到候选门槛时只解锁一次；杀死居民不会被累计历史人口误触发；失败结算后不生成新岛。
- 畜牧岛储粮能否撑过首轮羊繁衍、成年、宰杀和运输必须实测；没有可宰余量时正确留种，不能用不断补羊解决短缺。
- 王宫由实际工人建成，国王选自现有成年人；冲突开放与实际出兵门槛区分清楚，人口回落不撤销解锁但可阻止出兵。
- 暴怒按原概率尝试，不能绕过军粮、兵员、在外队伍、间隔、停火与生产保种约束；失败原因可见。和解、返乡、携粮及战利品不重复结算。

#### 五分钟平衡与可理解性

- 记录首次出生、成年、建房、第二岛出现、王宫完成、冲突开放、首次出兵、供奉和收魂的实际时间，确认玩家有时间经历全部阶段。
- 新开局最多只有4名初始化居民。若最终存活R人，要完成300魂，至少需新生296＋R人（第二岛已出现时）；若只出现第一岛，则至少需298＋R人。该算术只是必要条件，不是可通关证明。
- 同时验证30栋×4床位的住房上限、生产供给、保种、军粮和技能费用能否支撑目标。检查小人口长期增长及供奉是否导致灵力失衡。
- 15秒出生、20秒成长、20人新岛门槛、12成年人冲突开放、120份初始化粮食等均为候选；保留300秒期限，结合真实测试再确定最终出生节奏、供给、门槛和灵魂目标。不得用固定补人或强制战争伪造结果。
- 闪电2费、死亡返1灵力、3秒冷却保持原取舍；检查单靠闪电是否不足以完成目标，同时其他组合是否实际可行。
- 试玩者应能回答：“为什么正在建房？”“为什么没出生？”“为什么没有出兵？”“灵力从哪里来？”“现在继续养还是收魂？”若回答不了，优先改原因提示和过程表现。
