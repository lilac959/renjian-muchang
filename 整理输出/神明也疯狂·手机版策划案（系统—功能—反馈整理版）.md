### 一.1 游戏定位与核心循环

《神明也疯狂》是一款上帝模拟游戏。玩家扮演生命、天气、死亡三位神明，用9个技能干预两座岛上的两个国家。

- **核心循环**：观察局势 → 选择神明与技能 → 放置落点并预览 → 确认施放 → 查看实际结果 → 调整策略
- **核心矛盾**：人口越多，可收的灵魂越多，但粮食和住房压力也越大；文明越发达，越可能建成封魂工程
- **玩家不做的事**：不直接指挥任何居民。居民自主生产、建房、生育、研究、贸易和打仗

---

### 一.2 模式、目标与对局结算

#### 功能与胜负条件

| 模式   | 目标               | 成功              | 失败／结束            |
| ---- | ---------------- | --------------- | ---------------- |
| 标准挑战 | 50年内累计收集300个人类灵魂 | 累计灵魂≥300，立即判定成功 | 期限届满、人类灭绝或封魂工程完工 |
| 沙盒   | 无目标，自由观察与干预      | 无               | 人类灭绝或封魂工程完工      |

#### 对应反馈：结算页

| 结果   | 显示内容                                           |
| ---- | ---------------------------------------------- |
| 挑战成功 | 大字“挑战成功”、累计灵魂、用时（年和月）、两国最终状态、已达成的默契            |
| 挑战失败 | 大字“挑战失败”、具体原因（期限届满、人类灭绝或X国封魂工程完工）、已收集灵魂、与目标的差额 |
| 沙盒结束 | 结束原因、累计灵魂、经过年数。不显示魂数目标或差额                      |

结算页提供三个按钮：再来一局、返回主界面、查看日志。

### 一.3 双岛生产与居民生存

#### 功能与规则

| 国家  | 生产方式                                |
| --- | ----------------------------------- |
| 农耕国 | 清理野兽 → 砍树清地 → 开垦农田 → 居民耕作           |
| 畜牧国 | 留种养羊 → 羊群繁殖 → 居民宰羊收肉入库；没有栏位的羊进入公共牧场 |

**基础数值**

| 项目   | 数值             |
| ---- | -------------- |
| 房屋容量 | 5人／栋（必须已完工）    |
| 粮食消耗 | 2份／人／年         |
| 农田   | 2名工人，基础产量10份／年 |

**规则**

- 羊和野兽的数量都不算粮食。居民宰羊或拾取兽肉后，粮食才入库。
- 有空余住房且有余粮时才会正常出生。缺粮会拖慢发展并导致饿死。
- 房屋受损后，可用住房会减少，超出的人口露宿。
- 患病、享乐、暴怒中的居民不劳动。祝福不会让失能居民恢复劳动。
- 国家卡中的人口、住户、劳力、粮食必须与实际实体一一对应，禁止只改显示数字。

#### 对应反馈：出生、粮食、住房

| 事件      | 反馈                                                                       |
| ------- | ------------------------------------------------------------------------ |
| 出生      | 婴儿头顶显示小爱心                                                     |
| 缺粮      | 该国粮仓堆变空、变暗；显示橙色预警条“X国粮食仅够Y年”；国家卡中的粮食变红                                        |
| 饿死      | 日志记录“X国有居民饿死”，同时按死亡流程计魂                                                  |
| 露宿      | 露宿居民在屋外搭起帐篷；国家卡显示“露宿X人”                                                  |
| 房屋受损或烧毁 | 房屋冒烟并显示破损贴图；国家卡中的住房容量随之下降                                                     |

#### 对应反馈：世界中的可见状态

| 状态 | 画面表现 |
| --- | --- |
| 粮食存量 | 王宫旁的粮仓堆按存量分档显示（满、半满、见底、空）；缺粮时粮仓变暗 |
| 住房不足 | 露宿居民在屋外搭帐篷 |
| 房屋受损 | 冒烟、破损贴图；烧毁后留下焦黑废墟 |
| 劳动状态 | 患病、享乐、暴怒的居民分别有病态色、爱心、怒气等明显的外观区别 |

### 一.4 国家关系、战争与民变

#### 功能与规则

- **贸易**：两国都有余粮时，会自动进行贸易。
- **劫掠**：一方缺粮且关系紧张时，会派小队烧屋抢粮。
- **战争流程**：动员 → 粮食补给 → 实际行军 → 建补给据点或夺桥头 → 攻入本土 → 留下驻军。驻军数量决定占领区的反抗程度。
- **暴怒**：只提高国王的宣战倾向或强征倾向。是否真正出兵，仍取决于兵员和局势。
- **民变**：厌战度高时反复强征，可能引发民变。

#### 对应反馈：贸易与冲突事件

| 事件      | 反馈                                                                       |
| ------- | ------------------------------------------------------------------------ |
| 贸易      | 两岛之间出现货船，日志记录“X国与Y国交易粮食”                                                 |
| 劫掠      | 显示红色预警条“X国小队正在劫掠Y国”，点按可定位                                                |
| 宣战或强征   | 全屏短横幅“X国向Y国宣战”，播放战鼓音效；点按横幅跳到战场；战场在屏幕外时显示屏外指示                                        |
| 民变      | 红色横幅加日志，起义区域显示火把图标                                                       |

#### 对应反馈：战争与领土状态

| 状态 | 画面表现 |
| --- | --- |
| 战争 | 战旗、行军队列、补给据点；停火时战旗变为白旗 |
| 国家边界 | 总览视角下用淡色描边区分两国领土，包括占领区 |

### 一.5 科研、时代与封魂工程

#### 功能与规则

1. 同时满足以下条件后，居民会建学院：人口≥50、有足够余粮、有富余劳力。
2. 学士进入学院研究，文明依次推进冷兵器、热兵器、激光三个时代。
3. 医学进步会延长寿命，并降低疾病和瘟疫的致死率。
4. 文明后期会出现封魂工程。工程分阶段发出预警，**只有实际完工**才会触发结局。

#### 对应反馈：学院与时代

| 事件      | 反馈                                                                       |
| ------- | ------------------------------------------------------------------------ |
| 学院建成    | 金色Toast“X国建成学院，开始研究”；学院窗户亮起灯光                                                        |
| 时代升级    | 横幅“X国进入热兵器时代”，该国士兵外观随之更换                                                 |

#### 对应反馈：封魂工程阶段预警

| 阶段      | 反馈                              |
| ------- | ------------------------------- |
| 开工      | 橙色预警条“X国开始建造封魂工程”，工程建筑上方出现进度条   |
| 进度≥50%  | 预警条变红并缓慢闪烁，播放提示音效；工程在屏幕外时显示屏外指示               |
| 进度≥90%  | 屏幕边缘泛红，显示“封魂工程即将完工！”及剩余进度，并振动一次 |
| 工程受损或停工 | 进度条变灰，日志记录原因                    |

#### 对应反馈：建筑与时代状态

| 状态 | 画面表现 |
| --- | --- |
| 科研 | 学院建成后窗户亮灯；时代升级后士兵和建筑外观改变 |
| 封魂工程 | 工程建筑随进度逐段建起，上方显示进度条 |

封魂工程实际完工后的结算见“一.2”；屏外提示规则见“二.1”。

### 一.6 灵魂与灵力

#### 功能与结算规则

|     | 灵魂        | 灵力            |
| --- | --------- | ------------- |
| 性质  | 累计成绩，只增不减 | 可花费资源         |
| 来源  | 人类实际死亡    | 人类死亡，以及居民献粮供奉 |
| 用途  | 判定胜负      | 解锁、升级、施法      |

**计魂规则（由核心逻辑保证）**

- 每个人类只结算1次灵魂，在死亡实际发生的那一帧结算。
- 感染和受伤不提前计魂。
- 羊、野兽、恐龙、亡灵死亡都不产生灵魂。
- 尸体复苏为亡灵，以及亡灵再次死亡，都不重复计魂。
- 陨石毁屋时，只按屋内实际居民结算。空屋不产生死亡。

#### 对应反馈：死亡计魂与供奉

| 事件      | 反馈                                                                       |
| ------- | ------------------------------------------------------------------------ |
| 人类死亡    | 尸体处升起光点，沿弧线飞向顶部灵魂计数；灵魂数字跳动+1，灵力显示浮字“+X”，并播放短促的收魂音效。多人同时死亡时合并为一次大跳动，并振动两下 |
| 献粮供奉    | 祭坛处升起金色光点，灵力显示浮字“+X”                                                     |

### 二.1 界面布局与信息查看

#### 界面原则

1. **能画在世界里的，不做成面板**。粮仓存量、露宿、房屋损坏、天气、建造进度等状态，都由画面直接表现（见“三.1”及玩法系统各项状态反馈）。数字只在玩家主动查看时出现。
2. **按需出现，用完即收**。瞄准、确认、预警、屏外指示只在相关时刻显示，不需要时完全消失。
3. **常驻元素只保留5个**：菜单、灵魂（含剩余年数）、灵力、时间胶囊、神明卡组。
4. **点对象看信息**。隐藏的信息都可以通过点按对应对象直接查看：点王宫看国家，点居民看居民，点技能看技能。
5. **同一信息只出现在一个常驻位置**，不重复显示。

#### 功能、位置与交互

- **强制横屏**：竖屏时显示全屏提示“请横置手机”，同时暂停游戏。
- **安全区**：所有界面元素都避开刘海、挖孔和底部手势条（使用 `env(safe-area-inset-*)`）。
- **触控尺寸**：可点击元素不小于44×44pt，相邻按钮间距至少8pt。正文字号不小于12pt，关键数字不小于16pt。

```
┌──────────────────────────────────────────────────────────┐
│ [≡]           灵魂 123／300 · 剩38年        ◆45  [⏸ ×2] │ ← 常驻顶部栏
│                  ⚠预警条（仅有风险时）                    │
│◀⚔                                                        │ ← 屏外指示（仅在需要时）
│                     世 界 区 域                  [✓施放] │ ← 确认区（仅等待确认时）
│                   （双岛斜俯视）                    [✕]   │
│                                                          │
│ ┌生命┐┌天气┐┌死亡┐  [技能A][技能B][技能C]                  │ ← 常驻卡组
└──────────────────────────────────────────────────────────┘
```

**常驻元素**

| 区域   | 内容与交互 |
| ---- | ----- |
| 菜单 | 左上角“≡”按钮 |
| 灵魂 | 顶部中央大字。挑战模式显示“灵魂 123／300 · 剩38年”；沙盒模式显示“灵魂 123 · 第12年”，不显示目标和剩余时间 |

### 二.3 选择技能、瞄准与施放

#### 操作流程与模式

**选择神明与技能**

1. 点按神明卡，展开该神明的3个技能。在卡组区左右滑动也可以切换神明。
2. 点按技能按钮将其选中。再次点按同一技能即可取消选中。
3. 点按锁定的技能时，直接弹出解锁确认：“解锁瘟疫：18灵力 [解锁]”。

**两步确认模式（默认）**

1. 点按世界放置落点。范围技能显示预览圈，单体技能吸附并高亮目标。
2. 拖动准星调整位置，或点按其他位置重新放置。
3. 点按“✓施放”，或再次点按准星中心，完成施放。
4. 施放后技能保持选中，落点保留，方便原地连续施放。
5. 取消方式：点按“✕”、再次点按当前技能，或使用返回键。

**快速施放模式**：点按世界即直接施放，不弹出确认区。

**各技能的默认施放模式**

| 技能   | 默认模式          | 说明                             |
| ---- | ------------- | ------------------------------ |
| 闪电   | 快速：点按即施放（带吸附） | 费用低、冷却短，适合连点                   |
| 气候控制 | 选好选项后，点按岛屿即施放 | 见本节下方气候说明                        |
| 其余技能 | 两步确认          | 可在设置中逐项改为快速；陨石和流星雨改为快速时，需要二次确认 |

**防误触与精确瞄准**

- **准星上移**：拖动时，准星显示在手指上方（距离由配置提供，默认60px），避免手指遮挡。松手后，准星停在显示位置。
- **目标吸附**：单体技能会吸附点按位置半径24pt内最近的合法目标。若有多个目标重叠，弹出小列表供选择，例如“士兵A／士兵B／国王”。
- **自动放大**：如果预览圈在屏幕上的直径小于48pt（例如在总览视角下使用瘟疫），放置落点时镜头会自动平滑放大到落点，使预览圈达到可精确瞄准的大小。此功能可在设置中关闭；关闭后改为显示提示“放大后瞄准更精确”。

**操作提示**：选中技能后，底部显示“点按岛屿放置落点”（快速模式下显示“点按目标施放”）。每个技能只在前3次选中时显示，次数由配置提供。

**气候控制**

1. 选中技能后，底部弹出小面板：温度三选一，云量二选一（不收费）。
2. 选完后，点按岛屿即施放。
3. 面板会记住上次的选择。下次选中技能时，面板折叠为一行摘要，例如“高温·多云 ✎”，点按“✎”可修改。

**暂停中**：可以选技能、放落点、看预览，但“✓施放”按钮置灰并显示“已暂停”。快速模式下点按世界也不施放。

#### 对应反馈：选择、落点与取消

| 操作             | 反馈                                                |
| -------------- | ------------------------------------------------- |
| 点按或滑动神明卡       | 该卡上浮放大，展开3个技能，播放翻牌音效                              |
| 选中技能           | 按钮高亮并轻振；前3次选中时显示操作提示（见“二.3”）           |
| 放置落点           | 出现预览圈和准星，准星落下时轻振，弹出确认区；需要时镜头自动放大到落点  |
| 取消（✕、再点技能、返回键） | 预览圈收回，确认区隐藏，播放轻柔的收回音效                             |

解锁反馈见“一.8”；暂停反馈见“二.4”；收费校验与施放判定见“二.7”；各技能专属反馈见“一.7”。

### 二.4 模拟时间、暂停与调速

#### 功能与时间规则

**时间规则**

- 游戏内1年 = 30模拟秒。速度分为1、2、3倍，3倍速下1年约10现实秒。
- 冷却、祝福、灾害、气候都使用模拟时间，暂停时全部停止计时。
- 暂停期间仍可选择技能、放置落点、预览、查看信息、打开面板，但不能确认施放。
- 游戏切到后台时自动暂停，见“三.4”。

### 二.7 共用反馈、施放校验与事件记录

#### 共用反馈元素与通用原则

| 元素    | 用途        | 规格                                            |
| ----- | --------- | --------------------------------------------- |
| 选中高亮  | 当前神明卡和技能  | 发光描边加轻微放大，其余卡片变暗                              |
| 范围预览圈 | 范围技能瞄准    | 放置落点后显示，可拖动。合法时使用技能主色，非法时为红色虚线。圈中心有准星，准星旁显示费用和预估数量 |

| 详情卡   | 技能和对象说明   | 长按0.4秒弹出，显示名称、等级、说明；技能详情卡带升级按钮。松手后保持显示，点按外侧关闭 |
| 浮字    | 场景中的数值变化  | 从对象头顶上飘1秒后淡出。正面为绿色，负面为红色，灵魂为紫金色。**浮字是命中结果的主要反馈** |
| Toast | 汇总结果或失败原因 | 屏幕中上方（避开刘海）显示2秒。同类消息合并，例如“灵力不足×3”。点按可跳转到相关位置 |
| 按钮抖动  | 不能施放      | 按钮左右抖动0.3秒并闪红，伴随短促的拒绝音和一次振动                   |
| 触感    | 关键操作      | 选中技能振10ms，落点放下轻振，施放成功振20ms，计魂大跳时振两下，失败振30ms   |
| 屏外指示  | 屏幕外的重要对象  | 见“二.1”                                           |
| 预警条   | 持续风险      | 顶部栏下方的橙色或红色横条，只显示最紧急的一条，点按可定位                     |
| 事件日志  | 需要追溯的结果   | 不常驻。带时间戳，点按可将镜头跳转到事件发生处                           |
| 音效    | 每类操作      | 选择、施放、命中、失败、计魂各有独立音效，可整体静音                    |

**通用原则**

1. 先校验再收费。校验失败时不扣灵力、不进入冷却、不播放施法动画，只显示失败原因。
2. 放置落点和拖动准星都不收费，只有确认施放时才收费。
3. 施法动画不等于命中。命中结果以实际结算为准，并另行展示。
4. 施法成功但没有产生效果时，要明确说明“没有效果”及原因，并且不计入默契次数。
5. **结果小结按需显示**：范围技能、流星雨，以及产生多项结果的施法，结束后显示一条结果小结Toast，例如“陨石：击杀野兽2，损坏房屋1，人类死亡3（+3魂）”。闪电等单体命中只显示浮字，不弹Toast。
6. 冷却期间仍可放置落点和预览。此时准星中心和“✓施放”按钮显示冷却读秒，冷却结束后自动亮起。连续点按时只提示冷却，不重复弹出Toast。

| 情况             | 提示文案             | 表现                                    |
| -------------- | ---------------- | ------------------------------------- |
| 灵力不足           | “灵力不足：需要X，当前Y”   | 按钮抖动，顶部灵力数字闪红                         |

### 三.2 保存与读取

### 三.4 HTML手机端实现约束

**防止浏览器干扰**

- viewport 设置为 `width=device-width, initial-scale=1, viewport-fit=cover, user-scalable=no`。
- 画布设置 `touch-action: none`；页面设置 `overscroll-behavior: none`，防止下拉刷新和回弹。
- 禁用长按菜单和文字选择：`-webkit-touch-callout: none`、`user-select: none`。
- 统一使用 Pointer Events 处理触控，并按 pointerId 追踪多指。
- 在输入框中打字时，不响应游戏手势。

**系统返回与全屏**

- 用 History API 压入状态，拦截安卓返回键，按“二.2”手势总表的顺序处理。到达“打开菜单”这一步时不退出页面。
- 安卓使用 Fullscreen API 实现全屏。iOS 不支持时，提示“添加到主屏幕”以获得全屏体验（需提供 PWA manifest）。
- 横屏锁定先尝试 `screen.orientation.lock`；失败时显示“二.1”的竖屏提示。

**音频与触感**

- 音频在首次触摸时解锁（iOS 要求由用户手势触发播放）。
- 触感反馈使用 `navigator.vibrate`，可在设置中关闭。不支持的设备（如iOS）静默跳过，不报错。

**后台与性能**

- 监听 `visibilitychange`：切到后台时自动暂停并自动存档；回到前台时保持暂停，提示“点▶继续”。
- 渲染分辨率最高按2倍 devicePixelRatio 计算。
- 画质分低、中、高三档。低档减少粒子和屏幕震动，并限制为30fps。
