# 核心循环配置

`人间牧场·可配置表.xlsx` 已按新版核心循环重建，移除停用系统参数。工作表包括全局参数、居民与生产、操作设置、技能基础、气候、界面文本、资产与使用说明。

游戏通过 `game/config.js` 加载 `game/rules.json`。Excel 是维护入口，JSON 是运行输入；`配置目录.json` 定义字段、单位、范围和表归属。工作簿不含当前人口或库存。

```powershell
npm run config:check
npm run config:sync
```

在根目录或开发目录运行。需要 Python 3，无第三方Python依赖。程序读取工作簿，检查必需ID、重复、类型、单位、范围、技能编号、神明归属及部分联动约束，列出差异后原子替换JSON。错误包含工作表、行和字段，上一份有效JSON保持不变。

黄色单元格是主要数值入口。空白保持原值，必需字段和技能不能通过删除行移除；删除标记明确填写时会报告引用约束。技能编号1—9固定，每神3技能。名称、说明与界面文本可编辑，但界面布局与动态句式仍由代码负责。

修改后刷新页面并开始新局。候选参数状态独立保留；目标300魂仍待验证。具体时序与结果见 `../reports/core-balance.json`，不是通关保证。

美术资产表记录Three.js场景、用户三神卡牌和合成音频。GLB替换入口为game/assets/models/manifest.json；为空时使用真实几何占位。
